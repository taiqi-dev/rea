# Tiny Glade：UI Motion 分类与已恢复的静态链

2026-10-22，Pacific Time。回答按钮点击、聚焦、出现/收起、整排布局和菜单切换的实现问题；独立实现规格见 [145](145-independent-cozy-ui-motion-spec.md)。本轮只读游戏制品，没有运行游戏、操作输入或检查用户工程。

**工具栏的关键做法是把交互状态、归一化动画进度、尺寸倍率和布局分开。** 出现与聚焦使用三次缓出；选中反馈使用另一条短脉冲曲线。动画后的尺寸进入 Taffy 布局，因此按钮变大时可以带动邻居重新排布。主菜单使用 `toolbar::mei` 另一条路径，不能将工具栏常数套到所有界面。

| 动效类别                   | 玩家看到的作用             | 本轮静态结论                                                                         | 边界                                        |
| -------------------------- | -------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------- |

| 聚焦 Focus                 | 指向/导航到按钮时变大      | 独立进度，目标倍率表包含 1.2 和 1.5                                                  | 两个查询标志选择倍率，尚未逐类对应所有按钮  |
| 激活反馈 Activation        | 点击或选择后的短促回弹     | `UiPlaySelectAnimation` 有独立幅度、时长和进度，消费多项式脉冲                       | 该组件的全部写端、所有鼠标/手柄触发尚未接齐 |
| 拒绝反馈 Rejection         | 点击锁定项时的反馈         | `UiClickEvent`、`UiLocked` 到 `UiPlayLockedAnimation` 的处理入口，存在另一条振荡倍率 | 不是已证实的水平 shake；完成命令尚未全解    |
| 布局联动 Reflow            | 一个按钮放大，其他按钮让位 | 动画倍率进入布局尺寸，布局结果再生成位置和大小                                       | 具体邻居移动取决于父布局、间距、文本下限等  |
| 父子展开 Context reveal    | 选主项后出现一排子项       | 父聚焦位可写入子项显示位，子项再走出现动画                                           | 没有建立按序号逐项延迟的证据                |
| 界面切换 Screen transition | 主菜单/设置进入、退出      | `EscMenuState`、模板插槽、Mei 节点复用与布局入口已定位                               | 整屏平移、淡入、退出等待与精确时长仍未知    |

这里的英文只是用于我们自己的动效分类，不是声称恢复了原作的设计文档。聚焦也不严格等于鼠标悬停：工具栏含导航输入，菜单控件另有热键路径。

## 工具栏：目标状态与播放进度分开

实际入口如下，符号直接函数和泛型系统签名交叉核对：

| 函数                          | VA            | 本轮用途                                 |
| ----------------------------- | ------------- | ---------------------------------------- |
| `ui_animation_state_update`   | `0x14297C0A0` | 读取交互状态和 Bevy `Time`，更新动画进度 |
| `ui_focus_animation`          | `0x14297AC10` | 聚焦倍率                                 |
| `ui_appear_animation`         | `0x14297B230` | 出现倍率                                 |
| `ui_select_animation`         | `0x14297BA90` | 选中脉冲                                 |
| `ui_locked_animation`         | `0x14297B540` | 锁定项事件及反馈                         |
| `ui_show_if_parent_in_focus`  | `0x14297E500` | 父聚焦到子项显示                         |
| `taffy_finalize_element_size` | `0x1429815D0` | 倍率到布局尺寸、消费后重置               |
| `TaffyLayout::perform_layout` | `0x142989F80` | 调用 Taffy 布局计算                      |
| `taffy_update_drawables`      | `0x142981260` | 布局输出到位置/尺寸记录                  |

`ui_animation_state_update` 的 PDB 签名包含 `Query<(&UiInteractionState,&mut UiAnimationState)>` 和 `Res<bevy_time::time::Time>`。选定指令读取 `Time+0x58` 的 float。这里称它为本系统消费的 `dt`；没有证明它在所有暂停、菜单或时间缩放情况下都是 unscaled time。

下面的字段名由读写用途归纳，不是恢复的原始成员名：

| 对象偏移               | 已追踪用途                 |
| ---------------------- | -------------------------- |
| `UiInteractionState+0` | 出现进度的正/负方向来源    |
| `UiInteractionState+1` | 聚焦进度及父子展开的输入位 |
| `UiAnimationState+0`   | 出现进度 `p`               |
| `UiAnimationState+4`   | 聚焦进度 `f`               |
| `UiAnimationState+0xC` | 聚焦方向切换的短状态标签   |

出现进度在 `0x14297C50E–0x14297C529` 选择符号，在 `0x14297C2C2–0x14297C2D4` 相加并 clamp：

```text
p = clamp(p + (show ? 4 : -4) * dt, 0, 1)
```

显示目标反向时沿已有进度返回，没有在这段把 `p` 无条件清零。目标稳定、系统持续运行、输入 `dt` 按秒增长时，从 0 到 1 的名义时间为 **0.25 秒**；不是实测墙钟时长。

聚焦在 `0x14297C48F–0x14297C509` 按方向使用 `dt/0.2` 或 `dt/(-0.2)`，再限制到 `[0,1]`，同时写回标签 0、1 或 2。标签参与分支，反向时有可能一次更新不推进进度，不能简写成完全无门控的 `f += ±dt/0.2`。持续同向推进的名义全程为 **0.2 秒**。

**构造演算：出现与收起。** 初始隐藏、`p=0`，显示位打开且收到 `dt=0.05`，则 `p=0.2`。再推进 0.05 秒得到 `p=0.4`；此时关闭显示位，下一次 0.05 秒更新回到 `p=0.2`，没有先跳回 1 再播放退出。该演算来自所选指令，不是游戏录像。

## 三次缓出与叠加倍率

`utils::easing_functions::EasingFunction::apply` 位于 `0x140DEDCD0`。聚焦和出现的调用分别在 `0x14297AD86`、`0x14297B3EC`，另一个出现迭代分支在 `0x14297B479`；都传入 `0x143607840` 的枚举常量 6。跳表 `0x1431FF458` 的第 6 项指向 `0x140DEDE94`，其实际计算为：

```text
E(t) = 1 - (1-t)^3
appearFactor = E(p)
focusFactor = 1 + (focusTarget-1) * E(f)
```

这是 **ease-out cubic** 的结构对应，名称归类基于公式。目标倍率表在 `0x143607200`，包含 float 1.2 与 1.5；`0x14297AD5E–0x14297AD70` 根据两个查询标志的或值选择，尚未逐个回溯其控件类别，不能写成“所有普通按钮固定放大 1.5 倍”。

出现和聚焦均乘到 `TaffyNode+0x10` 的临时倍率。选中和锁定反馈也写同一倍率，所以是多个状态因子的组合，而非每次点击重新创建一个整套动画对象。不同系统的完整实际调度仍有缺口；这里说明数据依赖，不承诺所有命令在同一帧发布。

**构造演算：缓出。** `E(0.2)=0.488`，`E(0.5)=0.875`，`E(1)=1`。因此出现动画前半段已经完成较多尺寸变化，尾段逐渐停稳。收起若直接倒走同一进度，速度轮廓随之反转；不能未经证据称原作另配了 ease-in 退出曲线。

## 点击/选择与锁定反馈各有一条曲线

`ui_select_animation` 的系统签名明确消费 `UiPlaySelectAnimation`，不是名字相近的 `UiAnimationState`。从 `0x14297BEEF–0x14297BF54` 可归纳本段组件的三个 float 为幅度 `A`、时长 `D`、进度 `q`：

```text
q = clamp(q + dt/D, 0, 1)
u = 0.1 + 0.9*q
selectFactor = 1 + A * (4*u*(1-u))^2
```

它先鼓起、再回到 1，不是另一条单调缓出，也没有在所选路径积分弹簧速度。`q==1` 时向 ECS Commands 追加完成命令（`0x14297BF66–0x14297BFA1`）；其最终删除/恢复操作和执行屏障尚未全部恢复，不能仅凭“完成”推断立即销毁实体。

输入一侧已经有更具体的候选：`render_taffy_ui_to_widgets` 在 `0x14297D40B–0x14297D46E` 检查 `dragged()==3`，追加含 float `0.2,0.2` 和零进度的命令载荷。独立小函数 `DragState::is_started`（`0x140901020`）实际比较的也是 tag 3，因此这一路属于开始交互，而非只能在鼠标释放时发生。该命令回调和选中组件的最终插入尚未完全接齐，**不能把载荷的 0.2 秒写成所有点击动画的已证实时长**。

另一路 `clicked()` 在 `0x14297D5E3–0x14297D647` 后写入事件记录。`ui_locked_animation` 的签名实际包含 `MessageReader<UiClickEvent>`、`Query<&UiLocked>` 和 `UiPlayLockedAnimation` 查询。其反馈段使用 `x=(5*q-1)*π`、`1+A*sin(x)/x` 形式乘尺寸倍率（`0x14297B991–0x14297B9FF`），选定初始化载荷含 `0.1,0.3`。这支持“锁定反馈与选择反馈分开”的结论，不支持“所有禁用按钮左右晃动”。本段未见 `x≈0` 特殊处理；独立实现应使用稳定的曲线或处理数学极限，不照搬该局部表达式。

**构造演算：选中脉冲。** 为演算自行取 `A=0.2,D=0.2`，从 `q=0` 开始，倍率为 1.02592；累计 0.1 秒后 `q=0.5`，倍率约 1.19602；累计 0.2 秒时回到 1。峰值在 `q=4/9`，倍率为 1.2。这里的参数是构造输入，不能借候选命令载荷冒充所有按钮配置。

## 一排按钮：显示传播、尺寸变化、重新排布

`ui_show_if_parent_in_focus` 的 `0x14297EA11` 读取父交互记录的 `+1`，`0x14297EA63` 写子记录的 `+0`。后续附加条件还可能覆盖该值，因而“父聚焦即可无条件显示任何子项”过强；但父子状态到出现进度的静态连接成立。

尺寸消费闭合到如下路径：

1. `taffy_finalize_element_size` 在 `0x142981A9E–0x142981ADE` 读取基础二维尺寸、`+0x10` 倍率和其他缩放来源，相乘得到待用尺寸。
2. 有文字组件时还读取 `TextFragment::bounds` 并取逐分量 max（`0x142981AEC–0x142981AF8`）。因此尺度归零不独立保证文字控件的布局和命中都归零。
3. `0x1429816BC` 调用 `taffy_mut_style`（`0x1423909C0`），后者写入两个尺寸值并调用 Taffy `set_style`。`0x1429816C7` 将本节点临时倍率重置为 **1**，防止跨次消费累乘。
4. `TaffyLayout::perform_layout` 中存在 `compute_layout` 的实际调用（`0x14298A0D2`、`0x14298A15C`）。
5. `taffy_update_drawables` 调用 Taffy `layout`，在 `0x1429813B4–0x1429813D3` 把布局位置加半个尺寸写成中心，并保存二维尺寸。

这解释了**尺寸变化经布局造成相邻按钮移动**的可行链，而不是证明存在一条单独的“邻居平移 tween”。若多个子项同次打开，其出现进度可以同时推进；本轮没有找到按按钮序号写延迟的闭合链。不能把这种整体展开误写成 stagger，也不能因未找到就断言游戏所有界面都没有 stagger。

**构造演算：布局联动。** 自行假设横排中按钮 A 宽 100、间距 20、左侧固定，B 的左边为 120。A 通过倍率变成宽 150，若 B 仍紧随 A，则 B 左边变成 170。B 移动 50 来自重排，无须自己的位置动画。真实居中排布、padding、父宽和文字下限会改变结果；这不是原作像素实测。

## 进入/退出界面：另一条菜单路径

选定 `assets/ui/menu/esc.ron` 主要配置 Horizontal、Vertical、Gap、Padding 和模板插槽，包含 `logo`、`contents`、`bottom`、`buttons` 等入口；横排和间距的声明不是时间线或逐项延迟证据。

`do_gui_escape_menu`（`0x14033DFA0`）确实调用 `MeiContext::reuse_or_create_node`（`0x14072C2D0`）并装配模板/插槽；菜单状态、取消和工具退出的已有输入研究见 [133](133-tiny-glade-confirm-cancel-input-mapping.md)、[135](135-tiny-glade-menu-tool-exit-and-timber-cleanup.md)。本轮还读到：

- `menu_button`（`0x1407339E0`）走节点 ID、`child_with_global_id`、`get_content_mut_impl` 与 `TextFragment::set_text`，有稳定节点/内容复用入口。
- `mei_pre_update`（`0x14072D1D0`）处理输入和 widget 状态；部分控件 `pre_update` 的热键路径设置同一个激活位。例如 `0x140729540` 的分支调用 `MainActionSet::just_pressed` 后置位 `0x20`。
- `mei_post_update`（`0x14072EEF0`）实际调用 `compute_min_size_with_children`、`place_childen` 等布局函数，再走控件内容渲染。所选菜单控件还有文字/矩形渲染路径。

上述是菜单搭建和输入/布局入口，**还没有恢复整屏进入/退出的最终 transform、opacity 曲线和动画完成发布条件**。也没有证明 `widgets::impl$6` 等编号与所有可见控件逐一对应。不能把工具栏的 0.25 秒、1.5 倍和三次缓出直接写进主菜单结论。

**构造场景：切换菜单。** 从主暂停页切到设置页，已有证据支持状态分支选择模板内容、按 ID 建立/复用节点、布局并渲染。旧页是否保留到退出动画结束、新页是否等待、两页是否交叉淡化，目前均为 Unknown；独立设计的可打断切换方案见 145。

## 检查结果和剩余缺口

| 状态         | 范围                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| Passed，静态 | 所选出现/聚焦/脉冲算术；尺寸倍率消费和重置；布局输出位置/大小；菜单布局入口       |
