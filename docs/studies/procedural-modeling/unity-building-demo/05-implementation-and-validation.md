## 2. 操作界面

工具栏：选择、放窗、挂灯、点火、加水、破坏、保存、加载、Reset；参数面板调宽深高/屋顶升高。候选预览显示支持合法性与拒绝原因。

环绕相机：鼠标拖动转视角、滚轮缩放；选择和拖窗由当前工具控制，输入冲突在M0处理。数值面板可按ID选择目标并执行命令，自动测试不需要凭截图猜位置。

诊断开关：开口矩形、Damage网格、Solid碰撞、附件支持、owner/revision、屋顶可见性。恢复初始场景的Reset按钮有明确名称，不在加载失败后自动触发。

## 4. EditMode测试入口

| 测试 | 真实语义 |
| --- | --- |
| WallFrameTests | 四墙O/e/n、厚度和内净尺寸；转角接触 |
| CutoutUnionTests | 无洞/单洞/相交/包含/触边/全域Air；Solid+并集面积守恒 |
| WallMeshTests | 索引有效、有限值、预期法线、边界侧面；位置合并后的闭合 |
| ColliderPartitionTests | 合并矩形面积与Solid面积相等，内部不重叠，不覆盖Air |
| AttachmentCommandTests | 净洞与asset bbox分离，移窗owner替换、支持/越界拒绝、重复序号 |
| ElementTickTests | 10/50步数值、加水当步灭火、石材拒绝、TooWet/Destroyed/Air拒绝 |
| PermanentDamageTests | 窗移动/屋顶重建/缩小再扩大不复原Destroyed格 |
| SupportCleanupTests | 灯失支撑清理、窗移除后重新派生，循环必终止 |
| SaveValidationTests | DTOround-trip、完整度不变量、域外damage、版本/坏数据和引用验证 |

优先测试纯Domain入口，不创建复杂Editor场景来验证矩形面积。测试不照抄私有方法内部实现；面积、占用、状态与所有权等不变量是实际契约。

## 5. PlayMode与真实工作流检查

程序创建最小场景或打开固定测试scene，验证Physics射线只查询Solid层，洞中心无墙碰撞、实体点有碰撞；还要验证Selection代理不会被误算成墙。隐藏屋顶观察内壁、洞四边和正反面。

记录原/新revision和同一帧禁用旧碰撞的行为，等待Unity完成销毁后核对存活资源。加载失败注入文件读写错误及无效DTO，证明当前场景保持。存档测试使用自己目录与测试文件，不触碰用户原存档。

真实交互需验证候选红色/拒绝原因、从洞上方拖窗、灯开关、灭火反馈及损坏清理。数值命令测试不能独立证明鼠标操作顺畅。

M7记录实际机器、Unity完整版本、包锁摘要、运行构建、对象/网格/碰撞/灯数、重建耗时及截图。帧率/耗时目标在有实测后制定，不先把“60fps”当验收承诺。REA的Node测试不代替Unity验证。

## 6. 风险与分阶段处理

| 风险 | 首版处理 | 扩展入口 |
| --- | --- | --- |
| AI资产不适配 | 程序占位+独立尺寸/挂点验收 | 单资产替换后重跑A1–A3 |
| 开口可见但仍挡碰撞 | Solid分格同源生成BoxCollider | PlayMode射线与实体测试 |
| 重建复原损坏 | DamageCell/Piece为权威数据 | A7–A9跨重建/读档 |
| 窗/灯失支撑遗留 | 附件有限清理循环、owner释放 | A5/A11及资源计数 |
| 火水顺序依赖 | 固定步、明确命令顺序和整数损耗 | 日后传播改快照聚合 |
| 屋面/转角微缝 | 专用矩形收口、接触坐标/视图检查 | 曲墙/任意相交独立算法 |
| 规模变大后重建慢 | 先小场景正确，再dirty局部化 | 测量后决定分块/Jobs/实例化 |

未做：本轮只编写规格、夹具和文档/算术核验；没有EditMode、PlayMode、Editor或Windows构建结果。没有生成AI模型、安装依赖或复制原游戏代码/资产。上述风险均未被文档检查消除。
