# 建筑几何：墙、房子、窗洞与破坏洞

本文指定[最小demo](README.md)自己的CPU几何算法。借鉴原研究的“逻辑形状与派生产物分开、粗开口与构件协商”原则；不复用原指令、网格、raw tag或GPU距离场常数。先选择直墙矩形扣洞，完整闭合几何比原作画面裁剪更适合本demo的碰撞验证。

## 1. 建筑足迹与四墙拼装

建筑中心在(0,0,0)，X为宽W，Z为深D，Y向上。北/南墙占足迹的完整宽度；东/西墙缩短到D−2t，位于南北墙的内边界之间。这样四个厚墙体只接触，不在转角重复占据体积。

每墙有稳定ID、外面起点O、沿墙单位e、外法线n、长度L、高H、厚t。坐标转换：

```text
P(u,v,d) = O + u*e + v*(0,1,0) - d*n
0<=u<=L，0<=v<=H，0<=d<=t
```

| 墙 | O | e | n | L |
| --- | --- | --- | --- | --- |
| north | (-W/2,0,D/2) | (1,0,0) | (0,0,1) | W |
| south | (W/2,0,-D/2) | (-1,0,0) | (0,0,-1) | W |
| east | (W/2,0,D/2-t) | (0,0,-1) | (1,0,0) | D−2t |
| west | (-W/2,0,-D/2+t) | (0,0,1) | (-1,0,0) | D−2t |

默认W=6,D=4,t=0.2，因此north/south长6，east/west长3.6；内净宽5.6、内净深3.6。楼板顶部Y=0，向下厚0.15；墙从Y=0起，避免地面顶面与墙内底面大量共面。

首版通过此专门矩形布局收口，不实现任意二维轮廓offset或建筑间相交。转角测试检查接触坐标、微缝及重叠；没有把这个布局叫通用接缝算法。

## 2. 开口数据与来源

墙上开口表示为墙坐标矩形`[umin,umax]×[vmin,vmax]`，从d=0贯通至t。每条记录必须有owner和kind：Window、Door或Damage。

窗/门切口是由当前附件定义派生的，移动时按owner替换；破坏矩形来自永久Destroyed单元状态。存档不重复保存一份可与附件坐标冲突的窗洞cache。

窗口净宽/高来自窗口类型契约，中心来自附件。默认窗中心(2,1.6)、宽高1.2，开口为`[1.4,2.6]×[1.0,2.2]`。窗移到u=3，则为`[2.4,3.6]×[1.0,2.2]`，旧owner开口不存在。

输入要求坐标有限、宽高>0、宿主存在。可操作窗须距墙外边界至少0.1m，四角支持区域不被其它开口/破损吃掉；初始门洞特许vmin=0。窗口间重叠首版拒绝；Damage可与既有窗/门洞相交，由几何取并集处理。几何算法本身支持重叠输入，不能依靠UI资格掩盖它的错误。

## 3. 矩形并集扣洞：二维分格后挤出

对单墙先把所有开口裁到`[0,L]×[0,H]`，保留原owner列表。完全在外的历史Damage单元不产生本次几何，但原状态不删除。无效Window输入在命令层已拒绝，不到生成层静默裁短窗。

1. U边界收集0、L、0.5m损坏网格线、所有矩形umin/umax；V收集0、H、网格线和vmin/vmax。
2. 升序排列；相差≤1e−5m的边界合并，边界/成员处理顺序固定。长度≤1e−5的区间不生成面。
3. 对每个相邻U/V区间，用中点判定是否在任一开口内；有则Air，否则Solid。采样足够，因为全部开口边已经加入边界集。
4. 所有开口共同决定占用，不分别挤出几个“各自有洞的墙”再叠加。
5. 正面积Solid产生d=0外面和d=t内面。
6. Solid邻接Air或墙域外时，沿边生成穿厚度的侧面；Solid邻接Solid不生成内部面。

每面给明确的预期法线、UV和Unity正面索引顺序；在正反观察测试中核验。硬边处分开法线顶点，位置一致；不要因为顶点法线分裂就误报几何不闭合。检查闭合时可先按容差合并位置再检查边。

```text
WallBuild(definition, attachments, damage):
  holes = DeriveWindowAndDoorCuts(attachments)
          + DeriveDestroyedCellCuts(damage)
  partition = SplitDomainByAllEdges(definition, holes)
  occupancy = ClassifyUnion(partition, holes)
  renderFaces = OuterInnerFaces(occupancy)
                + SolidAirBoundaryFaces(occupancy, thickness)
  colliderRects = GreedySolidRectangles(occupancy)
  return renderFaces, colliderRects, supportQueries, owner/revision
```

输出不是原作算法的恢复伪代码，是本demo的独立选择。首版使用普通Mesh API并保留索引检查；Unity Mesh允许程序提供顶点、法线、UV和三角索引，参考[Unity 6000.0 Mesh](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Mesh.html)。

## 4. 碰撞必须与占用同源

对同一Solid网格执行确定的贪心矩形合并：按v后u扫描未访问Solid格，先向u扩，再按该宽度向v扩到完整未访问Solid行。每个合并矩形生成一份BoxCollider，世界中心为`P((u0+u1)/2,(v0+v1)/2,t/2)`，尺寸为`(u1−u0,v1−v0,t)`，旋转按墙局部轴设置。

若WallView已位于O且局部X/Y/Z对齐e/up/n，collider的局部center应为`((u0+u1)/2,(v0+v1)/2,-t/2)`；不能把上述世界P再次赋给BoxCollider.center。也可以创建放在世界中心的Collider子对象并用center=0，但第一版统一前一种表示。墙Mesh同样在WallView局部坐标`(u,v,-d)`生成，避免重复应用墙变换。

无洞整墙可合成一个BoxCollider；有洞时由多个Solid矩形覆盖墙体，Air中不放collider。不要保留一块整墙BoxCollider让窗洞仍挡射线。BoxCollider的center/size是局部坐标，父变换保持单位缩放，参考[Unity BoxCollider](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/BoxCollider.html)。

玩法选择代理放独立layer：窗框/灯可有选择盒，但不作为实体墙碰撞。测试“射线穿窗”只查询Solid层；可选玻璃阻挡规则首版关闭并在UI说明，不能让选择代理使验证误失败。

## 5. 双坡屋顶、山墙和室内边界

屋脊沿X。对任意屋面横向z，外表面高度选择：

```text
y(z)=H+R*(1-|z|/(D/2))
|z|<=D/2+E，|x|<=W/2+E
```

默认R=1.2、E=0.15：屋脊Y=4.2，墙顶交点Y=3，出檐边Y=2.91。两坡各为矩形平面，程序生成沿面法线向内0.08m的厚板及端面。该定义让出檐保持相同坡度，不把屋顶简单拉成一块任意AI mesh。

X=±W/2处补程序三角山墙，顶边按坡线，下边Y=H；山墙向内有厚度。楼板、墙、山墙和屋面共同提供第一版内外边界。山墙碰撞使用同生成三角棱柱的凸代理，屋面可用沿坡的BoxCollider。屋面与山墙接触区允许有明确的构造搭接，不冒称联合成一个全局流形mesh；分别检查可见穿缝和碰撞缺口。

首版不开屋顶窗，也不破坏屋面/山墙；墙洞和木梁足以验证状态闭环。是否可进入的角色控制器/导航没有实现；仍可用自由相机检查内壁和洞厚。

## 6. 表面和小件铺排的接入

墙外观先使用木/石色板；贴图或shader必须在已有几何开口上工作，不能取代真实开口。以后添砖/板实例时，布局使用同一holes并集和damage状态，各实例仍以逻辑WallId及布局地址定位；网格或GPU槽位不做永久损坏身份。

窗框覆盖边缘只能改善视觉，不能遮掩洞侧壁缺面。首版洞侧壁归宿主墙生成器；框体/玻璃归window owner；破损边缘也归墙。接缝职责因此可直接检查，详见[03](03-attachments-fire-water-and-damage.md)。

## 7. 构造演算与边界例

默认north一面6×3墙，0.5m分格为12×6。无洞时72格Solid。加默认窗后：U共15边界/14区间，V共8边界/7区间；洞占4×3=12格，Solid为98−12=86格。墙实体体积为`(18−1.44)*0.2=3.312m³`。

按每Solid格两面、每邻Air/域外边一侧面实现，前后172 quad，域外42边段、洞边14边段，共228 quad，即912个面分裂顶点、456三角形。可进一步合并共面面片，但须保持开口、UV与法线；不能把这个未优化数量当实际帧预算。

再毁单元(8,3)，矩形`[4,4.5]×[1.5,2]`与窗不重叠，增加0.25m²开口；墙体积降至3.262m³。灯挂点(4.25,1.75)正落在破损中心，支持失效。两个相交Damage矩形应扣并集面积，不重复扣；洞触底时不生成悬空底侧壁。

测试还覆盖：同边界重复、极窄区间、整墙Air、洞触顶/侧、完全外部历史损坏、无效非有限输入、转角坐标和窗/碰撞layer过滤。

未做：未生成Unity Mesh或实测碰撞；本轮核对算法定义和独立算术。风险：容差、绕序、UV及屋面搭接需要真实Editor观察；复杂曲面/建筑相交须另选算法，不能把本方案扩称任意3D开洞。
