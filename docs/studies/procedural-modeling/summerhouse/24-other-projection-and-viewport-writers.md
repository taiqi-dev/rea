| level0       | 主 CameraController `6732`、两份 UniversalAdditionalCameraData `7384/8109`；无 PlanarReflectionRenderer 或 PixelPerfectCamera。另有 ImageRenderer `8255`。                                                                                                                                          |
| level1…4     | 每关一件 PlanarReflectionRenderer：`513/434/626/472`，相应 GO `43/37/48/47`。四件 `m_Enabled=1`，各 GO 及父 `Level Environment` 的 `m_IsActive=1`；每件引用16个确认为 `WaterObject` 的本地组件。                                                                                                    |
| 反射配置     | 四件均 `rendererIndex=1`、`renderScale=0.5`、`renderRange=500`；mask 分别为 `87/247/247/87`。这些是序列化初值，不代表四关同时加载或每帧都绘制。                                                                                                                                                     |
| RendererData | [09](09-lod-writers-and-pass-order.md)的发行资源已把默认 index 0 接到唯一 PixelateLayer feature，index 1 是无该 feature 的另一 renderer。插件 `ValidateRenderer 06000023 / IL_0022…0038,007E…007F` 在 index 1 有效时保留它，缺失才回退默认。当前资源的 index 1 确实存在；运行中更换 pipeline 另证。 |

水体组件的 `OnEnable 0600003B / IL_0011…0016` 调 `EnableReflections 06000040`；后者在 `AllowReflections` 与 `VREnabled` 条件后于 `IL_000F…001B` 订阅 `RenderPipelineManager.beginCameraRendering`。静态构造器 `06000059 / IL_000A…000B` 将 `AllowReflections` 初始置 true，不能据此排除之后更改；场景加载、VR 门及实际回调均未运行。

`OnWillRenderCamera 06000046`先在 `IL_0000…0025` 检查相机上下文及水体 bounds 的视锥可见性，在 `0044…0068` 排除 Overlay。通过后按源相机查字典，缺失时调用 `CreateReflectionCamera 0600004F / IL_0000…00FF`。后者**新建**隐藏 Camera，`IL_002C…0031` 先 `CopyFrom` 源相机，`IL_0047…0079` 设置反射相机类型、depth 与完整 rect，`IL_00E0…00E9` 把配置 renderer index 交给新增的 AdditionalCameraData。`CreateRenderTexture 06000050 / IL_001B…004E` 以源相机 `scaledPixelWidth/Height × clamp(renderScale × pipeline.renderScale, 0.25, 1)` 截断为整数宽高，再赋给反射相机 targetTexture；它是反射纹理大小，和主相机 PixelateLayer 的 Wlow／Hlow 是两套目标。

核心 `UpdatePerspective 06000054` 的两个相机实参是 `arg.1` 源、`arg.2` 反射：`IL_0110…012A` 读取源 `worldToCameraMatrix` 并乘反射矩阵得 view；`0154…0187` 基于反射相机视图及镜面剪裁平面调用源 Camera 的 `CalculateObliqueMatrix` 得投影；**`01F0…0201` 的两个 setter 都以 `ldarg.2` 为接收者**，分别写反射相机的 `projectionMatrix` 与 `worldToCameraMatrix`。回调 `IL_00ED…0102` 调此方法，`013A…0141` 再以 `m_reflectionCamera` 调 `UniversalRenderPipeline.RenderSingleCamera`。主相机在所读直接链中只作为参数源、可见性检查及复制来源；不能把水体斜裁剪矩阵视为主相机的像素锁。反射相机最终 native 矩阵数值、GPU 常量和画面未观测。

**Answered（有界静态）**：五场景注册状态、四件水体组件和16个水体引用各自的资源连接、反射新相机的 P/V 写入目标、index 1 选择、主／firstpass／水体程序集及 URP／Core／2D 的所列 setter 直接 CIL 命中，阴影事件相对普通相机提交的顺序。**Partial／Unknown**：运行时场景加载与动态组件、反射回调及水体可见性、native Camera getter／setter／viewport 状态、GPU 常量、其它未扫程序集和反射／native 间接调用。旧 native Ghidra timeout 条件未变，本轮未重开或重试。不能由这些有限扫描得出全游戏绝无主相机像素对齐；也没有证据把水体反射矩阵说成主相机像素锁。
