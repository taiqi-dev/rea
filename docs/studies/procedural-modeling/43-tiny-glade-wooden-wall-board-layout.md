# Tiny Glade 普通木墙板：方向、切分、合并与弯墙贴合

木墙板与[木骨架](38-tiny-glade-timber-layout-and-window-avoidance.md)各有生成入口。本轮恢复木墙区域先扣粗洞，再按方向均分、重连/合窄板、沿长向随机分段，并通过扩展墙空间和采样器生成直板或曲梁。它不是按固定二维网格铺板后只删掉窗内板条。

真实外层 `80AFC7→144A4C0 construct_wooden_wall_boards`。该入口raw长度/样式/形状资格分支尚未全部命名；下述规则只用于已确认的正常有限路径。精细显示见[39](39-tiny-glade-wall-and-timber-rendering.md)，稳定种子见[44](44-tiny-glade-stable-randomness.md)，证据与复核见[47](47-tiny-glade-four-systems-evidence-ledger.md)。

## 1. 粗洞差集和精细窗口列表是两条输入链

三个planner先实际调用 `1484310 remapped_wall_cutouts`：

```text
FinalizedWallHoles.holes_no_duplicates(C2B5C0)
→ 过滤20B记录的raw byte（+10hex）非零
→ 复制16B AABB
→ 追加arch_openings_to_aabb2(14853F0)
→ BoardWallSpace.remap_x映射左右边界
```

过滤字节的所有业务枚举未恢复，不能把结果说成全部窗户。X边界接近首尾（1e−4）时分别锁到0或扩展周长，其他位置用映射结果的min/max；Y保留。

精细窗口另在 `144A98E→A6A370`、`144A9B7→13E9710` 初始化WindowCutLists，随后为每构件查询packed窗口列表。**这条精细候选列表不是上述粗区域差集的同一个生产源。** 前轮[17](17-tiny-glade-window-wall-reconstruction.md)的相关连接已按本轮证据修正。

## 2. 矩形差集会按排板方向选择切法

`1484710 subtract_wall_cutouts` 先严格测试正面积相交；只接触边缘时保留原区域。给原区域B和相交I：

| 方向参数 | 初始四条差集分块 |
| --- | --- |
| 1 | 上下全宽条、左右中间条 |
| 0 | 左右全高条、上下中间条 |

只有正宽、正高子矩形进入结果；同一数学差集可以得到不同矩形组合，后续排板和合并仍会改变数量。

该helper最多进行**16轮完整cutout扫描**。每轮处理全部输入范围；若本轮没有变化就返回，有变化才回到轮数检查。`0x10`不是16个窗户、16条cut或产品容量限制。

### 构造例：相同面积，不同分块

B=[0,4]×[0,3]，I=[1,3]×[1,2]。方向1产生上下[0,4]×[0,1]/[2,3]和左右[0,1]/[3,4]×[1,2]；方向0产生左右[0,1]/[3,4]×[0,3]和上下[1,3]×[0,1]/[2,3]。总面积都为10，但它们接下来形成的板条可以不同。

## 3. 基础条宽采用精确均分

`14887E0 subdivide_region_into_planks` 选定尺寸d和目标w：

```text
N=max(roundf(d/w),1)
边界_i=start+d*i/N, i=0..N
方向0: 分X，形成竖条
方向1: 分Y，形成横条
```

本函数没有RNG。caller的选定目标尺度包括：

| 调用位置 | 目标数值（约） |
| --- | --- |
| `144AB1A` | .2944 |
| `144BDA2/144D7D9` | .3944 |
| `144EC0D` | .3694 |
| `144FD6D` | .3944 |

这些是分支传入值，不能命名为全材质固定板宽。round得到条数后，实际每条尺寸为d/N；不会保持w并把余数另留成最后一条。

### 构造例：余量由所有板共同承担

区域[0,2]×[0,1]，方向0、w=.4，N=5，X各宽.4。方向1、w=.3，N=3，Y各高1/3；不会出现三条.3加一条.1。

## 4. “竖板planner”中的区域也可能改为横排

`14536D0` 调用 `14871B0 classify_region_orientation`，再把返回方向送均分函数。名称不是固定方向契约。

它在区域左、中、右三个沿墙位置采样，正常有限输入需全部满足：

```text
region.minY > lower(s)+.05
region.maxY < min(globalTop,upper(s))-.05
```

严格相等不通过；缺样本使用lower=0/upper=1的分支，不是直接放行。余量通过后，比较左侧参考切线与中/右切线，任何 `abs(dot)<.85` 强制方向0；等于.85通过。最后仅当 `width/height>.5` 选择方向1。

globalTop是实际caller输入标量，尚未完整绑定原业务名，不称永远来自屋顶。abs(dot)也允许反向平行，不能改写成仅同向一致。

### 构造例：靠边和弯曲会改变选择

三个样本lower=0、upper=8、globalTop=8，regionY=[1,3]，余量通过。直切线dot=1，width=1、height=2，宽高比恰好.5，仍方向0；width=1.2则方向1。若中点切线偏45°，absdot≈.707<.85，即使宽高比>.5也返回0。

## 5. 洞后区域重连和窄板合并分别发生

普通horizontal路径先扣洞，按raw类别/身份及几何相邻条件重连区域：X两端各差≤.01，Y相交或间隔≤.001时，选定分支合并Y上下界。随后再次均分，再调用窄板合并。圆形horizontal路径却先均分Y、再扣洞、再合窄板；顺序不能统一。

`1488BE0 merge_narrow_planks_horizontal` 只处理height<.1的40B板记录。候选需控制字段/身份兼容，Y范围能在.01容差内相遇，X交宽为正。多个候选选交宽最大的，相等时后遇候选可替换。

合并时移除两条，在共同X范围内合Y上下界；共同范围两侧的非空余片继续保留。它不是直接取两个AABB的总包围矩形。后续循环还可能合并余片，并有处理次数诊断门槛，不当作窗口/板总数量限制。

竖向窄板对应width<.1，交换坐标后按最大Y交高选择；共同Y范围拼宽，保留上下余片。

### 构造例：保留两侧残条

兼容字段的窄A=[0,4]×[1,1.06]，B=[1,3]×[1.06,1.5]。共同X=[1,3]，得到[1,3]×[1,1.5]，并保留A的[0,1]×[1,1.06]、[3,4]×[1,1.06]。这是一次合并，不能保证最后恰好三个实例。

容差允许填很小的缝，因此整个重连过程不能无条件承诺严格数学面积守恒。

## 6. 长板沿长向递归随机切分

`14882C0 split_oversized_board_piece` 使用待处理stack。每次弹片段，选定长向尺寸严格大于上限就切成两子片推回，否则接受。

上限来自输入结构的Y/X两个标量，各先max(.05)；完整上游配置未知，不填成固定“最大4米”。短维度均分与长维度递归是两个阶段：

```text
方向0沿Y: cut=Ymin+(Ymax-Ymin)*(.3+.4U)
方向1沿X: cut=Xmin+(Xmax-Xmin)*(.15+.7U)
```

每子片按WallID、pieceIndex及长轴端点float位模式重新混合seed，详见[44](44-tiny-glade-stable-randomness.md)。这不是先均匀截成固定长度，再给接缝加一点噪声。

### 构造例：递归长板

方向0，Y=[0,4]、limit=2。第一次U=.25，cut=1.6；[0,1.6]接受，[1.6,4]还长2.4。再给U=.5，cut=2.8，最终段[0,1.6]、[1.6,2.8]、[2.8,4]。

这些U是构造值，未声称某实际seed的输出。上限相等直接接受，不进入这次严格超长分支。

## 7. 板面用扩展墙空间重映射

`1483D90 BoardWallSpace.new` 取得原shape，实际调用expand(.125)，求扩展曲线长度。无shape时保留原长度。它建立的是板面坐标系统，不能泛化为所有mesh顶点统一沿法线移.125。

`1483E90 remap_x` 先把s限制在原周长范围。一般分支用 `s/oldL*newL`；矩形特殊分支选择原边及对应扩展边，计算：

```text
d=clamp(s-sourceEdgeStart,0,sourceEdgeLength)
P=P0+unit(P1-P0)*d+.125*edgeNormal
t=clamp01(dot(P-Q0,Q1-Q0)/max(|Q1-Q0|²,1e-20))
mappedS=expandedEdgeStart+t*|Q1-Q0|
```

P0/P1为原边，Q0/Q1为对应扩展边；法向由实际edge-normal helper产生。源零长/无效方向另有分支，不属于这个正常公式。

### 构造例：矩形转角不能只按周长比例缩放

P0=(0,0)、P1=(4,0)、normal=(0,−1)，Q0=(−.125,−.125)、Q1=(4.125,−.125)，边起点均为0。s=2得到P=(2,−.125)、t=.5、mappedS=2.125。

一般分支oldL=8、newL=9、s=2得到2.25。两个例子属于不同分支，不能用统一比例缩放替代矩形投影。

## 8. 样本、周期边界与切线回退

`1483630 WallSampler.new` 生成20B样本：二维位置、remappedS、lower与upper。已确认lower来自输入Vec3.y，upper来自另一采样标量；有shape时位置由扩展shape查询，无shape回退原XZ。

样本按s排序；距离≤.001的邻样本合并，保留已有位置/s，lower取min、upper取max。闭合分支复制首样本并将s加newL作为末样本。它没有按固定.001间隔重采样。

`1483090 sample_pair_at`：周期时fmod并修正负余数，非周期clamp；二分查相邻s，`t=clamp01((s-s0)/max(s1-s0,1e-4))`。空数组返回显式tag；端外可复用首末样本。

`1483320 tangent_between` 插值两端位置并归一化弦。弦平方长≤1e−4时，再用中点±max(.001L,.01)求局部弦；仍小才返回(1,0,0)。1e−4是平方长度阈值。实际ctor由切线构成normal=(−tz,0,tx)，或使用矩形原边方向。

### 构造例：贴墙采样

样本0：pos(0,0)、s=0、lower=0、upper=2；样本1：pos(4,0)、s=4、lower=.2、upper=3。s=1时t=.25，位置(1,0)、lower=.05、upper=2.25。周期L=10、s=−.2先映成9.8。

两端形成直弦时tangent=(1,0,0)、normal=(0,0,1)。若闭环两端碰巧同点，先尝试局部差分，不是立即丢弃或任意选随机方向。

## 9. 直板与曲板实际类型不同

ctor有前48B为仿射transform的80B直板输出，也有圆形/特定上缘路径：

```text
14530C0 emit_curved_horizontal_wall_board_piece
→ AAA870 CurvedHalfTimber.new_curved_xy
→ seed / flags2 / packed窗口列表
→ 五组16B写入80B曲梁记录
```

这条路径真实builder确定曲梁类型，不能用同址grow_one的WoodenPlank别名改称仿射木板。

曲板要求L>.01、height≥.05；角端点按周长周期归一化，right angle<left时加2π。窗口查询横向范围也展开跨接缝右端。

构造例：L=10、left=9、right=1、orientation=0，角范围约[5.654867,6.911504]，查询范围[9,11]。height=.05通过这项门槛，.049不通过；L=.01不通过。

最后还有坡屋顶横板中点缩界路径：若两高度处屋顶query返回[1,5]和[2,4]，原板[0,6]，较窄范围消费例为[2,4]；query全部形状算法未恢复，此例不能替代完整坡屋顶模型。

## 10. 独立实现与剩余边界

可以独立设计区域差集、方向资格、精确条宽均分和长向随机接缝，并把窄片合并限制在共同交宽/交高，保留余片。曲墙则为板面建立明确坐标变换和采样器，直板与曲板用不同的类型化输出。

未做：未恢复35KB ctor全部样式、noise、上缘阶梯和坡屋顶分支，未绑定所有尺寸上限来源，未运行游戏或恢复原始资产。

风险：粗洞与精细cut列表不能混用；planner名称不等于所有区域方向；同大小记录不等于同类型；容差和门槛附近的float32舍入可能改变合并/计数。
