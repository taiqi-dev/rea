# Tiny Glade 道路穿墙：洞口范围与多个开口

发行版把道路覆盖沿墙转换成一条有高度的采样轮廓，再从连续正值中找开口、接续闭合首尾和细分长段。道路身份在四栅格相加时已被合并，因此这条路径不是逐条道路与墙求解析交点，也没有证据支持通用多边形布尔并集。

本篇地址均为同一匹配 EXE/PDB 的 RVA。证据身份、工具限制和原始记录见 [30 证据账本](30-tiny-glade-road-arches-evidence-ledger.md)。公式来自发行版指令；例子使用构造输入，没有运行游戏。

## 输入与中间状态

| 输入或产物 | 已确认用途 | 尚未确定 |
| --- | --- | --- |
| `PathRastersResources.as_float_grid`，`BFABF0` | 返回四份独立栅格 view | 四份 CPU view 与具体道路类别的字段映射 |
| 原墙 `Vec3` 点序列 | 世界 XZ 取样、切向和侧向，Y 用于后续轮廓 | 原曲线点距及生成规则 |
| 墙 `+78/+80` 标量数组 | 值严格大于 0.5 时抑制对应覆盖 | 完整业务含义 |
| 墙 `+28C` 标量 H | 覆盖转换成初始抬升量的尺度 | 完整参数来源、单位和默认值 |
| 墙 `+88..B8` | 重采样后的曲线对象 | 所有退化输入的处理 |
| 墙 `+C0/+C8/+D0` | 抬升数组的容量、指针、长度 | 不能继续当原始 u8 道路遮罩 |

`sample_wall_path_intersections` 的 `7FD57D` 实际调用四 view helper。取样 helper `A7D8D0` 读 u8、除以 255，行步长为 512；世界坐标先用 `xz/extent+0.5` 映射，调用者传入 extent=(130,130)。一个全局字节选择两种像素对齐：`uv*512−0.5` 或 `uv*512`，各有相邻索引夹紧，随后执行双线性插值。没有读取该字节的运行值，所以不能断言本机当前是哪种对齐。

GPU 另有已确认的联合排除场：`paths/combine_path_exclusions.precomp` 在文件偏移 `46E–5D6` 取 `path_mask` 和三份 `cobblestone*_mask` 的 R，求和后夹到 [0,1]。它支持 GPU 的四场合并职责，不能凭名字反推 CPU view 顺序或声称 CPU 拱门读取该 GPU 图。

## 洞口宽度：中心与墙两侧一起取样

在同一个世界位置 X，先计算：

```text
F(X) = clamp(Σ bilinear(raster_j, X), 0, 1), j=0..3
```

沿墙点 P，构造 XZ 切向和侧向单位 n。首点以前两个点外推虚拟前点；其余点使用上一点和当前点。除中心外，还在四个半径上采两侧：

```text
r_k = k/8                  k=1..4，即 0.125、0.25、0.375、0.5
w_k = 2*exp(-2*(k/4)^2)
c(P) = [F(P) + Σ w_k*min(F(P+r_k*n), F(P-r_k*n))] / [1+Σ w_k]
```

中心调用在 `7FD8FE–7FD978`；偏移、exp、min、加权及归一化在 `7FDA33–7FDC5F`。两侧取较小覆盖，使只靠近墙一侧的道路与覆盖墙两侧的道路产生不同数值。距离是发行版世界坐标数值，尚未证明等于现实米。

**构造算例。** 中心 F=.8；四对两侧的较小值依次为 [.6,.4,.2,0]。权重约 [1.764994,1.213061,.649305,.270671]，归一化后 c≈.505118。若中心和所有两侧都为 .8，则结果仍为 .8；若两侧每对至少一侧为0，只有中心项贡献，结果约 .163331。两条道路同点贡献 .6 与 .7，则 F 被夹为1，在此计算中不再保留两个独立道路身份。

## 沿墙平滑、阈值和精确零边界

`7FDDE5–7FDEEE` 对采样索引做五项平滑：中心权1，±1权 `.606530666`，±2权 `.135335281`。仅纳入存在的索引，分母也只累计存在项。这段循环没有周期索引，闭合接续在稍后处理。

抑制数组值>.5时将覆盖置0，否则保留平滑值。之后以 **coverage>.05** 判断激活。两点跨过门槛时计算：

```text
λ = (.05 − c_prev)/(c_curr − c_prev)
P_boundary = lerp(P_prev, P_curr, λ)
```

λ<.999的分支插入边界点，并把它的覆盖记为 **0**，不是 .05（`7FE284–7FE395`、`7FE9F0–7FEDA9`）。还存在激活点间高度差绝对值>.05插中点、局部段距>.1重新取道路中点，以及重复点/高度跳过分支。已确认这些条件，尚未得到任意输入下完全等价的重采样程序。

最后 `7FEEC6–7FEFEE` 生成初始抬升：

```text
lift_i = H*(1−exp(−5*coverage_i))
```

`7FF05C` 构造新曲线，`7FF0B5–7FF126` 替换曲线及抬升数组。后续 `lift>0` 消费的是这一结果。该指数式虽与早期公开原型相似，本篇是独立核到发行版指令后确认，不能因此把原型其余常数一起带入。

**构造算例。** 覆盖从 .02 到 .12，λ=.3；点从 x=0到1，零边界落在 x=.3。假设 H=3、c=.4，则 lift≈2.593994。单个中心覆盖 .8、邻居全0，五项完整邻域平滑后约 .322096；实际两端因分母变化会不同。

## 多个开口：连续区段、扩张与首尾合并

`calc_path_wall_segmentation`，`801390`，先构造 `profile_i=wallPoint_i+(0,lift_i,0)`，再在 `80190F–8019D1` 扫描连续 lift>0 的 run。

若正值 run=[a,b)，候选范围为：

```text
start=max(a−1,0)
end=b+(b<sampleCount ? 1 : 0)     // end不含
```

少于两个索引的候选不保留。扩张提供邻接的零边界样本，而不是固定世界距离扩大洞口。

当墙原始字段 `+258!=2`、至少两条候选、第一条 start=0、最后一条 end=liftCount，`8019D7–801A23` 删除末候选，并令第一条：

```text
first.start = last.start − wallPointCount + 1
```

之后使用周期 `wallPointCount−1` 的 LoopRange，负索引按欧氏余数回到周期范围。`+258==2` 使用 line range；未追完整枚举业务名，保留原始条件。

**构造算例。** 点数7、周期6、lift=[1,0,0,0,0,0,1]，初候选[0,2)、[5,7)，周期分支接成[-1,2)，实际索引为5、0、1。line分支不作此次首尾合并。

没有看到通用的内部 interval union。lift=[0,1,0,1,0]生成[0,3)、[2,5)，两个扩张范围共享索引2，仍分别交给 `process_segment`。因此必须区分四种情况：栅格求和导致覆盖连接、平滑连接、连续正值自然成为一个run，以及闭合首尾特殊合并。不能概括成“任何接触的洞口都会并成一个”。

## 一个大开口如何细分

`process_segment`，`7FFF70`，保存每点1字节mask和8字节 `CurveInternalCoord`。两组输入长度必须一致，点数必须>1，否则走显式panic路径。端点写标志值0x02/0x04；内部按评分写0x01；均匀补点写0x08（分别对应位索引1/2、0、3）。这些位的共同用途由消费者的 `mask&0xF` 确认，尚不能把某一位直接命名为“可见石柱”。

`score_split_candidate`，`800CE0`，向两侧沿三维轮廓最多延伸2，遇到已标记点停止。对左右端A/B和候选P，计算三维投影Q，但最终评分为：

```text
t=clamp(dot(P−A,B−A)/max(dot(B−A,B−A),1e−20),0,1)
Q=lerp(A,B,t)
score=.5*(length(P.xz−Q.xz)+Q.y−P.y)
```

只考虑严格 score>.4 的候选，选择最大有效分；平分保留先前候选。标记一次后重新评分，新的边界会改变两侧延伸范围。候选在连接线之上可得负分，所以这不是普通三维点线距离。

**构造算例。** A=(-1,1,0)、B=(1,1,0)、P=(0,0,0)，Q=(0,1,0)，score=.5，可选；P的Y=.3时score=.35，不选；Y=2时score=−.5，也不选。此例假设A/B就是延伸后的端点，不预测特定游戏场景。

剩余无标记区域以XZ曲线长度L和间距S补分：`n=floor(L/S)`；n=1且L<1.5S时改为0，否则在k/(n+1)处均分。内插坐标另行保存，mask选择最近采样索引，所以精确边界可以不在原样本上。

S的数值来源在 `8016FB–8018CB`：墙+258>1时S=4；否则通过 `ShapeParameters.perimeter(A85220)` 取p，shape首个dword为0时a=clamp((p−10)/8,0,1)，其他分支a=clamp((p−9)/3,0,1)，S=2+2a。调用process时墙+2A0非零改传3（`801B46–801B69`）。这些字段的业务枚举未恢复，但数值计算已确认；不能把2–4称为所有墙统一的固定柱距。

**构造算例。** S=2：L=2.8无补点；L=3在1.5处补1点；L=4在4/3、8/3处补2点。结果不是简单的 `ceil(L/S)−1`。在shape原始tag0、未覆盖S的分支，p=14得到a=.5、S=3；p=20被夹到S=4。

## 下游输出与边界

`calculate_wall_path_segments_impl`，`13FB850`，收集低4bit非零的标记，每对相邻标记产生一条104字节记录；少于两处标记返回空结果。标量、Vec3、CurveU分别保存，首末点按上游精确内部坐标重新线性采样，覆盖mask索引所在位置。另有负Y与可选数组的高度限制，尚未完整恢复其业务含义，不能称作完整道路离地、屋顶裁剪或拱柱规则。

风险：采样/平滑分辨率和原曲线点距会影响洞边；静态分支不能证明运行中的所有画笔模式和退化场景。上述mask边界、初始抬升、最终石拱轮廓分别是不同阶段，不能混为同一个洞口形状。
