# Tiny Glade 普通砖墙：行高、分砖与错缝

发行版显示，普通墙先在墙坐标中生成高度边界，再按墙顶高度裁出每行可用范围，最后分砖、处理墙洞并输出实例。`.46` 是分行/分砖中的目标尺度，实际砖高、砖长由跨度、分段数量和随机边界共同决定。没有证据支持把它概括为固定尺寸砖网格。

本篇是匹配 EXE/PDB 的静态指令研究，地址均为 RVA。身份、原始记录与复核见[第十轮账本](40-tiny-glade-wall-layout-evidence-ledger.md)。转角采用独立生产者，见[转角与扰动](37-tiny-glade-brick-corners-and-noise.md)；最终显示见[CPU 到 GPU](39-tiny-glade-wall-and-timber-rendering.md)。

## 1. 实际入口与坐标

外层 `80AD25` 调用 `1446690 WallConstructor.from_curve`；内层 `1446B47` 调用 `846C00 split_into_random_rows`，`1446C81` 调用 `847DD0 trim_rows`。这些是直接调用事实。

定义 `L` 为曲线长度，`H` 为输入墙顶浮点数组的最大值，`bottom` 为输入底高。沿墙范围用归一化 `u` 表示，世界沿墙坐标为 `u*L`；行边界用归一化 `y` 表示，世界高度为 `y*H`。最终三维点还要经墙曲线映射，不能把二维 AABB 直接当世界水平平面上的矩形。

`1446930–14469D0` 使用可处理 NaN 的最大值链；有限 `H=0` 会退出。下文公式仅覆盖有限、递增跨度等正常输入。负高度、逆序中间界线、NaN 和零跨度的完整视觉结果未恢复。

构造器参数结构 raw tag=2 时使用 `[bottom,H]`。同时 raw style=3 时，把上限改成 `H'=max(bottom+.1,H-.64)`，并按新 H 归一化。tag≠2 时增加一个结构中的中间高度，形成 `[bottom,mid,H]`（`1446A48–1446AF9`）。尚未贯通这些 raw 值与玩家界面中的材质/样式名称，因此不命名为“所有石墙”或“所有木墙”。

## 2. 砖行高度：边界均分后扰动

`846C00` 对每对输入高度 `a,b` 处理。令 `D=b-a>0`：

```text
N = max(floor(D/.46), 2) + 1
c = min(.21/D, .495/(N-1))
t_0=0; t_(N-1)=1
t_i = i/(N-1) + (U_i-.5)*c,  i=1..N-2
y_i = ((1-t_i)*a+t_i*b)/H
```

N 是边界点数，初始行数为 N−1。`846F3E→DE8290→DE8BB0` 是实际随机分割链；`2E32A40` 的 public 符号确认纵向使用 `floorf`。`E02880 Rng.f32` 用浮点尾数拼接形成 `U∈[0,1)`；每段沿用局部 RNG 状态。

内部点世界偏移幅度为 `±.5*min(.21,.495*D/(N−1))`。`.21` 不是固定每行高度，也不是完整的 ±.21 扰动。

输出还有去重：前一个已接受归一化值 **大于零** 时，当前值与它距离严格小于 `.046/H` 才被丢弃；距离相等保留。前值≤0 时走接受分支（`846F95–846FD8`），所以不能把它写成无条件相邻去重。

### 构造例：1.9 高度的墙

选 `bottom=0,H=1.9`，三次内部 RNG 输入 `.25,.75,.5`：N=5，得到世界高度边界

```text
0, .4225, 1.0025, 1.425, 1.9
```

行高为 `.4225,.58,.4225,.475`。这是指定随机输入的公式演算，未声称某个实际游戏 seed 必然产生这些数。

## 3. 变化墙顶怎样截断每行

`847DD0 trim_rows` 逐对行边界计算采样门槛：

```text
threshold = (rowLow+rowHigh)/2 * max(H,.1)
```

然后 `848086→148ACD0 split_heightmap_by_threshold` 找墙顶数组中 **topHeight>threshold** 的连续部分；相等归入较低侧。跨越门槛时线性求交：

```text
t = (threshold-h0)/(h1-h0)
uCross = lerp(curveCumulativeU[i],curveCumulativeU[i+1],t)
```

实际 sink `847C10/847CD0` 保存开闭区间。输出是 32 字节记录，`+10/+14` 为归一化行高，`+18/+1C` 为沿墙起止 u；关联索引字段只恢复了消费用途。

一个泛型分支可先把墙顶样本加 `.46`，但当前外层 `80AD0C` 明确把该开关写成零，因此 **80AD25 这条普通墙调用不加这个值**。

### 3.1 范围量化及短段处理

精确 0、1 端点保留；其余端点按

```text
u' = clamp01(roundf(u/q)*q)
raw tag!=2: q=.092/L
raw tag==2: q=.23/L
```

量化（`848129–84818A`）。`2E32B00` 确认是 `roundf`，不可换成 floor。

tag≠2 且范围宽≤`.46/L` 时，程序按顺序执行：

```text
left'  = clamp01((left+right)/2-.23/L)
right' = clamp01((left'+oldRight)/2+.23/L)
```

第二式使用更新后的 left。这并非围绕原中心对称扩张。tag=2 时，只在 `L>.92` 的条件下删除宽≤`.46/L` 的范围（`8481C5–84828C`）。

### 构造例：起伏墙顶

令 `H=2,row=(.4,.6),top=[2,0,2],uSamples=[0,.5,1]`。门槛为 1，原可用区间是 `[0,.25]`、`[.75,1]`。取 `L=4.6,tag!=2`，q=.02，量化后为 `[0,.26]`、`[.76,1]`，世界宽为 1.196、1.104。

另取短段 `[.30,.34]`：先得 left'=.27，再得 right'=.355，世界宽 `.391`。原指令结果不足 `.46`，应保留原式；不能为了“合理”把它改成对称扩张。

## 4. 横向分砖：两种分支，独立种子

每个裁后行记录沿墙跨度为 `(uR-uL)*L`。结构还可按内部水平界线再分段，子段依次分砖；非递增界线跳过。

定义 raw 分支 `P=(style!=1) OR (当前trim记录不是最后一条)`。它不是对所有墙使用的统一材质规则。每个子段世界长度为 d：

| 分支 | 砖段数 K | 随机参数 |
| --- | --- | --- |
| P=true | `ceil(d/.46)` | `.32/d` |
| P=false | `K0=ceil(d/.69); K=K0+(K0&1)`，保证偶数 | `.05/d` |

请求 K+1 个边界，内部公式仍为 `i/K+(U−.5)*min(jitter,.495/K)`；首尾固定。实际 `14478AD–1447999→DE8BB0`，`2E329C0` 确认是 `ceilf`。相邻子段拼接会保留重复共同端点，后续迭代跳过非递增对，不产生零宽砖。

设 caller seed 为 S，纵向分行输出边界数量为 B，裁后记录索引为 r：

```text
横分 RNG       = S*0x154DF + B*0x159 + r*0x96A3DD
每砖辅助 RNG   = S*0x91E + B*0xDF + r*0x91FD
厚度 RNG       = S*0x15B3 + B*B + 0x2A6 + r
```

乘加遵循实际机器整数溢出规则。r 不是切窗之后的可见砖行序号，也不能不加区分地称为建筑总层数。

不同记录的独立随机分割能产生错缝。选定路径未见固定半砖交替偏移；P=false 还会仅保留奇数 brickIndex（`144845D–1448464`），这是间隔保留的特殊分支。完整样式树和上游是否加入其他错缝约束仍未知。

### 构造例：接缝为何不齐

S=7、B=5 时，r=0 横分种子为 612566，r=1 为 10484915。

P=true、d=3 得 K=7。内部第1/2界线输入 `.25/.75` 时，位置为 `.3755357/.9101786`，夹出的砖长 `.5346429`；另一记录若输入均为 .5，对应界线为 `.4285714/.8571429`。相邻记录的竖缝因此不同。

P=false、d=3 得 K=6。输入均为 .5 时每段长 .5；只保留奇数段会留下 `[.5,1]、[1.5,2]、[2.5,3]`。这个演算不适用于 P=true 的整行墙砖。

## 5. 行端扰动、厚度及最终剔除

`17E110` 为每个裁后记录生成 `R=(2U−1)*A`，其 RNG 混合为 `S*0x17D32+B*0x8BA`。仅当 A>0，才经 `144876E→846800 perturb_row_ends` 修改首砖左端或末砖右端：

```text
cap=.138/L
first: left  += R*min(cap,1.99*min(cx,1-mLast))
last:  right += R*min(cap,1.99*min(mFirst,1-cx))
```

cx 是当前砖归一化中心，mFirst/mLast 为首末砖中心。实际先判断 first，再判断 last；仅一段砖时只走 first，不同时改两端。内部砖不在这个 helper 中平移。若 cap 主导，世界移动为 `R*.138`。

外层幅度 A（`80AA04–80AAC2`）默认零；raw tag=2 的分支先设 `.046`，另一个尚未命名的 raw 谓词为真时用 `smoothstep(clamp01((x-.69)/.69))` 覆盖。未恢复 x 的业务字段名和谓词对应的材质，不把这条规则套给所有砖墙。这里的 A 与 ctor 保存的执行门槛同源。

### 构造例：首末砖长变化

L=3、K=7 均匀分割，A=.5、U=.9，R=.4。cap 主导时首砖左端、末砖右端各移动世界 `.0552`；首砖变短，末砖变长，内部共同界线不动。此 helper 未见自动 wrap/clamp 最终端点。

普通砖的基础 `.56` 经条件缩放及 `T=max(.05,base+.07*(U−.5))` 得到 **法向厚度标量**，随后乘墙法向形成实例第三基向量（`1444810A–14448125`、`14448B85–14448B8A`）。沿墙长仍由二维砖范围宽×L 得到。base=.56、U=.25 时 T=.5425，不能称砖长 .5425。

砖范围会进入已有墙洞切分（`1444888A→815BE0`），见[窗洞与砖木重建](17-tiny-glade-window-wall-reconstruction.md)。最终输出拒绝非正宽高、沿墙长<.03 的碎砖；P=false 另拒绝长<.184 的砖，并在高度>长度时把高度压成长度，中心下移以保持底边（`14448C38–14448DD6`）。这些筛选发生在布局后，初始边界数不等于最终实例数。

## 6. 独立实现原则与边界

可以独立实现“纵向连续边界 → 墙顶阈值区间 → 沿墙分割 → 洞口局部分解 → 实例筛选”的算法。应明确哪一层决定高度、哪一层决定长度、哪一层控制端点，以及哪些种子与行身份绑定。实现自己的错缝约束时，可显式控制相邻行接缝距离，不能把本次没有确认的规则归给原游戏。

未做：未运行游戏或测量实际场景；未贯通所有材质枚举、上游种子身份和所有退化输入。

风险：局部公式不是完整墙生成器；不同 raw 分支的规则不能混用。随机边界、墙顶切断、窗洞和 GPU 变形会进一步改变最终可见砖形。
