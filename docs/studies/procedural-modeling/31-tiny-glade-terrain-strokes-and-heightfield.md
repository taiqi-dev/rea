# Tiny Glade 地形笔刷与高度场

发行版地形编辑保存带坡面参数和高度尺度的折线笔画；GPU对每条曲线求距离，加入空间扰动，生成高度候选并取最大值，再结合水域/背景、平滑和量化。它没有在已选路径中把所有笔画高度相加，也不是直接把鼠标每个点Y当山体高度。

建筑地面采样见 [32](32-tiny-glade-building-ground-sampling-and-heights.md)，地基表面见 [33](33-tiny-glade-foundation-surfaces-and-cutouts.md)，读回和局部更新见 [34](34-tiny-glade-terrain-readback-and-local-updates.md)，制品、范围和未知见 [35](35-tiny-glade-terrain-evidence-ledger.md)。以下是匹配发行版指令和独立构造算例。

## 1. 实际绘制入口、状态与参数

由 `TerrainStroke.insert_or_morph_last_point(A00140)` 的候选caller反查，`C10BA6`在完整解码中确认位于 `ui_draw_terrain(C10580)`。该入口要求工具原始tag5，从Option<Vec3>取位置，以XZ半径.8圆检查地图边界；全部UI状态枚举未恢复。

`TerrainEditingData.new_stroke(B14280)` 分配ID、复制首点，初始化p=.4、H=2.5；计数>0x3FFFFE时返回None，UI显示warning，同ID冲突有panic。后续UI可改H，所以初值不是所有场景最终值。

| TerrainStroke偏移 | 数据与用途 |
| --- | --- |
| +0/+8/+10 | Vec3点容量、指针、数量，stride12 |
| +18 | 坡面参数p，GPU同时控制核心宽度 |
| +1C | u32 StrokeID |
| +20 | 高度尺度H |

**构造例。** 空map、counter7、点(2,3,4)：创建ID7、单点列表、p=.4、H=2.5，counter变8。是否被后续UI覆盖由另一个分支决定。

## 2. 末点改形与追加

`C10BA6` 实际传门槛.3；`A00140` 的规则为：

```text
没有点：追加首点
只有一点：新点到首点的3D距离>.001才追加
至少两点：已有末两点距离<.3则覆盖末点
否则在点数<1024时追加
```

比较的是**已有末段**，不是新点到末点的距离。精确相等走追加分支；达到1024点但仍满足改形条件时，可以继续覆盖末点。此helper没有固定每段=.3，也未见卷积/样条平滑。

**构造例。** 点列0→.2，新点.25覆盖末点；再输入.4，旧段.25<.3仍覆盖；随后输入.5，旧段.4≥.3，追加。这里用直线坐标演算，实际float边界可能有表示误差。

参数编辑 `A08D10` 要区分直接Set与增量：增量p夹[0,1]；增量H夹[0,20]，结果<1置0。直接Set分支没有相同的统一clamp。UI绘制的改点事件经 `terrain_stroke_changed(BFBDA0)` 汇聚成重算命令；点数组替换和参数编辑由 `edit_terrain_stroke` 直接发重算命令（`A09070/A094D0`），分别增加地形读回计数。两条消息路径不能混为统一的changed汇聚。

**构造例。** p=.9增量+.3得到1；H=1.2增量−.5得到0；直接Set H=.7可保存.7。两条未读改点事件在这次changed调用汇聚一个重算消息，实际频率仍取决调度。

## 3. GPU记录怎样表示笔画

`rasterize_terrain_stroke(9B16B0)` 跳过H≤.01或空点笔画，最多处理65536份活跃记录，越界有诊断。每条最多1024点，内存按偶数点数分配，但只复制实际点数。

每个Vec3只上传XZ，输出Vec2；Y没有直接参与这条GPU曲线。16字节 `StrokeInfo` 保存：

```text
deviceAddress：64bit
countAndID：(pointCount&1023)|(StrokeID<<10)
params：p在低half、H在高half
```

shader低10位计数0按1024解释，不能称为空笔画。half打包有软件/硬件转换路径和精度变化。

**构造例。** ID7、count3得到0x1C03；count1024得到0x1C00，shader恢复1024。p=.25、H=8打包为0x48003400；任意十进制参数不保证half精确表示。

CPU实际绑定global width=1.5，输出高度preset0xA、笔画索引0xC、岩石mask0xF、地形方向0xE、水域0x12及背景高度图。目标为512×512，shader局部组8×8×1，已核共同dispatch规则得到64×64组。像素中心世界XZ为 `(((pixel+.5)/dims)*2−1)*65`；pixel(256,256)约为(.126953,.126953)，不是原点。

## 4. 坡面与核心宽度

`terrain_editing/rasterize_terrain_stroke.precomp` 原文件 `1EC4–2070` 解出：

```text
p=clamp(unpackedP,.1,1)
w=3*(1−p)
angle=mix(90,10,sqrt(p))*.01744444482
r0=max(H/tan(angle),0)
r=r0/(1+r0/84)
```

p同时改变中心宽度与坡面衰减范围，不是直接的圆笔刷半径。弧度转换系数保留发行版实际值，未擅自替换为π/180。CPU及shader的H筛选边界略不同，不能混称所有输入统一H范围。

像素X对单点求圆距离，对多点遍历段：

```text
t=clamp(dot(X−A,B−A)/dot(B−A,B−A),0,1)
D=min_segments(length(X−A−t*(B−A))−w)
```

工作组还有基于tile中心距离/半径的提前跳过。零长度段和中心点归一化的完整防护未确认，不能用标准距离函数习惯补写epsilon。

## 5. 噪声、核心高度与笔画最大值

两层与StrokeID和XZ相关的确定性标量场修正距离：`D1=D−5*clamp(N1,0,1)`、`D2=D1−clamp(N2,0,1)`。指令含格点、hash与平滑插值，但未完整归纳噪声库，不赋Perlin/Simplex名称。

```text
q=clamp(D2/r,0,1)
coreNormalized=.05*H*exp(−5.5*q²)
```

另有两层高度噪声，第一项随(1−q)衰减，第二项振幅依局部导数和参数；完整表达式/真实噪声值未复现。因此本篇算例只演算明确的核心式。

逐笔画用严格 `candidateHeight>bestHeight` 选择胜者，同时更新StrokeID、法向/附属mask；初best=.01、ID=−1。平分保留先前胜者，但map遍历顺序未证明按ID排序。它是最大值合成，不是叠加。

**构造例。** 忽略噪声、水/背景和后续平滑，p=.25、H=8：w=2.25，角约50°；q=0/.5/1的核心世界高度为8/约2.022717/.032694（最后世界尺度乘20）。另笔画候选3时，q=.5处选3及其ID，不相加成5.022717。这些数值不是最终画面测量。

## 6. 复合、平滑与世界高度编码

最大值结果还经过水域R/G/B、地图边缘和背景高度复合；已核资源绑定与选定分支，但没有在本轮重建全部水岸/噪声逻辑。地图边缘分支在abs(X)>60或abs(Z)>60时读取背景图并过渡到65边界。最终归一化高度是这些处理之后的值。

原文件 `FC34–FC9C` 输出：

```text
hWorld=20*finalNormalizedHeight
encoded=(hWorld+2.5)/26.5
```

CPU随后将preset0xA→临时图→0xA作两轴高斯平滑，σ=2像素、半径ceil(2σ)=4，读R、边缘坐标夹紧、归一化权重并写所有分量。两pass实参、binder字段及shader已联合核对；这与采点门槛.3是不同阶段。

**构造例。** 内部R脉冲1，单轴中心约.204164，双轴中心约.041683。边缘的夹紧采样不同。平均和线性编码可交换，不代表max和噪声生成也能线性叠加。

## 7. 高度读回shader只量化，不再合成

`read_terrain_height.precomp` 分别读取地形图与视觉地形图，每线程取两个相邻像素R，夹[0,1]后：

```text
q0=uint(encoded0*65535+.5)
q1=uint(encoded1*65535+.5)
out=q0+(q1<<16)
```

两份map各512×512个u16，即524,288字节。shader本身没有再次合成水域/背景；CPU同键读回及[-2.5,24]解释在34。这建立归一化、编码值、u16和CPU世界高度的完整接口。

**构造例。** 最终世界高3编码约.20754717，量化u16=13602，解码约3.000160。区间内理想最近舍入误差上限约.000202182；越界会夹紧，不能套此误差界。

独立 `cache_stroke` shader虽有max缓存操作，本路径CPU caller未贯通，未把它画进已证主链；所选floor和拾取shader仅格式解析，不宣称全显示/拾取算法恢复。

未做：没有运行笔刷、实际参数编辑或退化场景，没有重建完整噪声库、UI初始H覆盖分支、全部附属mask和取消/历史路径。

风险：half参数、噪声、最大值、复合、平滑和u16量化共同影响最终高度；仅核心式不能直接重播画面。静态链也不能证明每次拖动的视觉延迟。
