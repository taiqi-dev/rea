# Tiny Glade 普通砖墙：转角收口与随机扰动

发行版在普通排砖之外，专门生成转角砖：先挑选近直角折点，再按高度分带，逐带交替沿进边/出边伸出；存活构件还会写回墙空间避让区。普通墙的柔和起伏则来自另一条按行边界生成的正弦参数链。

本篇是匹配 EXE/PDB 的静态指令证据。普通行布局见[砖行篇](36-tiny-glade-brick-row-layout.md)，GPU 后续变形见[绘制篇](39-tiny-glade-wall-and-timber-rendering.md)，身份、覆盖及复核见[第十轮账本](40-tiny-glade-wall-layout-evidence-ledger.md)。这里的普通墙转角与[建筑相交接缝](04-tiny-glade-intersections.md)是不同生产者。

## 1. 什么折点会产生转角砖

实际外层 `80A2B0→14299B0 add_wall_corners`；内部 `24BBFA0 find_corners` 对相邻非零边归一化后求点积 d，实参以 80°、100°经 cosf 得门槛：

```text
cos(100°) <= d < cos(80°)
```

即约 `−.173648≤d<.173648`，筛出接近90°的方向变化。这里是前后行进切线夹角，不是从角点向两侧发出的两射线内角。零长边导致非有限计算，不会进入这个筛选。

墙 raw tag≠2 时还检查闭合首点及相邻末段。闭合资格与后续坐标 wrap 使用不同 raw 字段，未完整命名枚举，不应根据数值自行赋予全局类型名称。

### 构造例：90°折点

prev=(0,0)、current=(1,0)、next=(1,1)。进边方向(1,0)、出边方向(0,1)，d=0，满足门槛。若转向30°，d≈.866，排除。实际输出还取决于高度、已有洞和样式筛选。

## 2. 转角分带与普通砖行不同

转角跨度 span=top−bottom，有限正跨度下：

```text
N=max(ceil(span/.69),2)
random_splits(N,.21/span,&seed)
```

`2E329C0` 已核为 `ceilf`。N仍是 **边界点数**：第一带消费两个点，后续复用前带终点，最多形成N−1初始带。普通行使用 `max(floor(D/.46),2)+1`，不能把两者合成一种层高算法。

内部边界同样受 `.495/(N−1)` 限制，固定首尾并随机移动内部点。每带抽取一次宽度：

```text
w=.92+.16*(2U−1), U∈[0,1)
```

末带且 raw wallTag≠2 时覆盖为 `.76`；另有 style/墙顶条件可覆盖为 `.56`。本轮未恢复全部条件的用户可见意义。这里的宽度属于转角候选，不是普通墙法向厚度 `.56` 的同一个变量。

## 3. 交替伸出与收口变换

设 corner_u 是角点沿墙世界坐标。带索引偶数用出边切线，奇数用进边切线；中心沿墙移动：

```text
偶数: uc=project(corner_u + (w/2-.28-.0385))
奇数: uc=project(corner_u - (w/2-.28-.0385))
yc=(bandLow+bandHigh)/2
候选尺寸=(w,bandHigh-bandLow)
```

`DEA610` 中 raw tag=1 用 fmodf 并对负余数加 L，实现周期坐标；其他 tag 将值限制在[0,L]。这个 helper 不等同于沿墙候选 AABB 的全部裁剪。

存活候选经墙曲线映成3D位置。`DE9410` 对有限非零水平切线(t_x,t_z)形成三个基向量：

```text
(tx,0,tz), (0,1,0), (-tz,0,tx)
```

再按候选宽、候选高和 `.637` 缩放（`142B1A6` 后）。这段是沿某一侧切线放置砖，未使用两侧方向的平均角平分线作为统一 miter。

### 构造例：上下带交替

bottom=0、top=2.07，N=3；指定分割输出[0,.5,1]，两带各高1.035。首带U=.5，w=.92，中心偏移+.1415并沿出边；若末带满足宽度覆盖资格，w=.76，中心偏移−.0615并沿进边。

这些高度和宽度尚未过所有后续条件。即使得到两带，也不能断言最终恰好生成两块完整砖。

## 4. 已有洞、碎片门槛与避让区

生产者把已有20B墙洞记录转成AABB，与转角候选相交时实际调用 `146C450`，修改40B候选队列。周期分支会对跨墙首尾的洞使用 ±L 副本。它与[普通窗洞切砖](17-tiny-glade-window-wall-reconstruction.md)关联，但本轮没有恢复所有裁剪分支。

最终尺寸检查有一个必须保留的差异：`142B0E9` 要求 **剩余 piece.width>.1**；`142B0F6–142B107` 的高度检查却读取 **原始 band AABB.height>.1**，不能改写成“每个碎片高宽都>.1”。末带特殊缩高路径另有剩余高度检查。

每个 emit 写64B编码实例，同时写20B `(uCenter,yCenter,width,height,tag2)`；最后 `142B5AA→InProgressHoleStorage.extend`。因此确认转角占用区进入墙洞存储。尚未证明这些记录在所有下游模式中都会按同一种规则被使用。

转角种子有两条实际数值链：同一角点附近、沿墙中心差<.01的洞记录，把中心Y经饱和整数转换后累加为 sumY。累加的是中心高度值，不是洞ID。

```text
随机分割/宽度RNG初始seed = cornerIndex + sumY
实例seed计数起点         = sumY
```

后者每个通过上沿检查的 band 组递增，组内裁剪拆出的片段共享实例seed，未加角点索引。上游洞记录的完整资格和实体身份仍未贯通。

### 构造例：周期接缝及筛选

L=4、uc=−.1或4.1，wrap分支分别得到3.9和.1；clamp分支分别得到0和4。跨界窗的副本也以±L平移，能够参与首尾附近的检测。

原band高.5、剩余piece宽.09时，宽度检查拒绝；宽.2通过这一项。若piece高度很小，也不能仅根据主高度guard声称它被拒绝，因为该guard读取原band高度；还需看所走的特殊路径和裁剪结果。

## 5. 普通行起伏：有符号哈希与正弦

通用参数生产者 `847990 BrickRowSine.new` 写24B记录，`847B40 sine_wave_deform` 消费它。独立 public 符号确认 `2E32B30=sinf`、`2E32BC0=truncf`。

定义 `sf(z)=z-trunc(z)`，它保留小数符号；z=−2.25时得到−.25，不是常见fract的+.75。

```text
h(y)=sf(sin((10*k*y+s)*12.989800453)*43758.546875)
p(y)=1000*sf(sin(2*h(y)*12.989800453)*43758.546875)
t=x*scale
M=.5+.5*sin(.2*t)
A=.06*sin((1+h(a)*M)*t+p(a))
B=.06*sin((1+h(b)*M)*t+p(b))
```

记录中保存h(a)、h(b)、p(a)、p(b)、scale及第一路资格字节。通用helper第一路资格是a≥.01；false时A=0，另一个输入开关为真时B=0。每路未经过后续转换时，绝对幅度不超过.06。这里的 k/s 是数值参数，尚未完整命名其上游业务身份。

## 6. 普通墙实例怎样取得四端值

`1446690` 在 `1447CDD–1447E7B` 内联同一哈希链，这条路径 k=1、s来自caller整数seed转float。哈希的两高度输入来自 `H*rowLow`、`H*rowHigh`，同一边界值使用相同波形参数；水平相位 t 则在归一化端点 u 处为 `L*u`。

`14484E9–14486D2` 计算 `[Aleft,Aright,Bleft,Bright]`。与通用helper相比，实际内联路径的A资格比较 **normalized rowLow≥.01**，不能换成世界高度≥.01。B关闭开关来自一个尚未命名的行索引/端范围比较。

P=false（[砖行篇](36-tiny-glade-brick-row-layout.md)中的特殊横分分支）时，B两端再执行 `.1*B+.1`。此时值域约为[.094,.106]；不能继续声称所有端值都在±.06内。

四值写入40B候选的附加字段。墙洞切分和细分后，子候选自己的附加值进入 CPU BrickTransform 的 `+30..3F`（十六进制），再编码到 GPU `+20/+24` 两个half-pair。裁剪过程中四值是否以及怎样重新插值尚未恢复，因此不能断言最初四样值总是原样上传。`94C790 encode` 和 GPU 双线性消费见[绘制篇](39-tiny-glade-wall-and-timber-rendering.md)。

caller传入整数seed后转换为浮点参与参数生成；完整上游身份及生命周期未确认，不能凭数值称为WallID或时间。CPU正弦、行端偏移、厚度随机和GPU空间噪声是不同层次的扰动。

### 构造例：波形开关与范围

给通用helper输入a=0、b=.46、k=1、s=0、scale=2、x=0：a端哈希/相位为零，a<.01使A关闭；第二开关为false时B=.06*sin(p(b))，为true时B也关闭。

普通内联路径若rowLow=.005、H=10，虽世界低高=.05，A仍被关闭，因为比较的是.005。若未转换B=.04，P=false路径得到.104。所有这些都是指定输入的算术例，未执行游戏。

## 7. 独立实现原则与边界

可以独立设计角点资格、交替沿边的收口构件及占用区反馈，让普通墙排布与转角细节分别负责。连续起伏可按墙行边界建立确定性的波形参数，保存四端值并在显示阶段插值。应为自己的数值范围、种子稳定性和裁剪插值建立明确契约，尤其区分带符号小数与fract。

未做：未完整恢复转角洞裁剪、石基转角、全部style条件和调度；未运行游戏、恢复原网格或验证真实场景。

风险：原始band检查与碎片检查不同；转角N不是实例数；正弦两路资格、特殊B转换和GPU后续加工不能省略。静态局部公式不代表全部场景的完整算法。
