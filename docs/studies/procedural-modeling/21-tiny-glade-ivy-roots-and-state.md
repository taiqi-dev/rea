# Tiny Glade 常春藤：起点选择与状态

本篇研究匹配发行版中 `ivy_spawner` 和 `IvyStorage` 的实际指令。常春藤以有身份的枝条点序列保存，另有根点副本、增长状态和叶片记录。起点选择、生长、修剪与显示分开执行；完整帧调度尚未恢复。

证据身份沿用 [00](00-evidence-and-scope.md)，本轮覆盖与本机证据见 [25](25-tiny-glade-ivy-evidence-ledger.md)。全部为离线静态研究，没有运行或改动游戏。本文中的坐标单位是发行数据单位，未另证为米。

## 起点从哪里来

`ivy_spawner`（RVA `BB4E60`，4451 字节）先要求上游资源的 `+20` 字节等于 1（`BB4ED3–BB4EDA`）。读取另一资源 `+130` 的原始模式值：小于 3 的分支使用光标附近的墙段候选；大于等于 3 的分支从现有墙候选中抽样。模式值对应哪些界面工具、资格字节怎样设置、多久调用，尚未追清。

光标分支通过空间栅格取墙段，`BB50CA` 调用 `closest_segment_index`，传入高度相关参数 0.5。选中后，将输入 XZ 点投影到线段：

```text
d = B - A
t = clamp(dot(p-A,d) / max(dot(d,d), 1e-20), 0, 1)
Q = (1-t)A + tB
```

这是 `BB50F7–BB5151` 的实际计算，不意味着候选函数本身使用普通点到线段欧氏距离；其评分和高度筛选见 [生长与贴墙](22-tiny-glade-ivy-growth-and-wall-following.md)。

另一分支对墙曲线取随机归一化坐标，并在 `BB53D8` 调用 `FastNoise.get_noise`；只有输出严格大于该噪声对象的 `+78` 阈值才继续。噪声类型及完整配置尚未恢复，不能指定为某种噪声算法。

## 贴到墙的哪一侧

取得墙身份后，用 `get_approx_u_from_pos` 找近似曲线坐标，限制到 `[0,1]`，再取当前曲线段和单位切线。墙侧法线来自二维切线旋转，并通过侧别判断或条件随机位选择正负。

起点在墙曲线上再加减 `0.68×0.5 = 0.34` 的法线偏移（`BB56BB–BB56F9`、`BB577E–BB57B9`）。这是起点布局参数；后续生长点的 `WallCoord` 转换使用另一偏移 0.315，两者不能合并成统一“墙厚”。

原始模式小于 3 时使用光标与曲线的侧别；另一分支还检查墙的原始类型字段，并在部分类型上用一个随机位选择侧别。没有把这些原始类型值命名为具体游戏墙材质。

## 起点之间怎样避免过密

`BB5815` 构建已有根点引用列表；专门解码的 `15F2910` 从每个 Ivy 的内嵌根点取引用，检查对象不是每个枝条点或叶片。

对有限输入，只有根点法线与新候选法线点积大于等于 0 时才计算距离。相反朝向的根点跳过这一密度排除。相同朝向的三维距离平方严格小于阈值时，整次生成退出：

| 原始模式 | 距离平方阈值 | 对应距离 |
| --- | ---: | ---: |
| `<3` | 0.25 | 0.5 |
| `>=3` | 2.56000018119812 | 约 1.6 |

位置和法线消费指令在 `BB586D–BB58CC`、`BB58ED–BB594C`。严格等于阈值时通过这一关；通过并不保证最终创建。

**构造演算。** 已有根在 `(5,0,0)`，法线 `(0,0,1)`；模式值取 0。新候选 `(5.3,0,0)` 法线相同，点积为 1、距离平方 0.09，因此拒绝。候选改为 `(5.5,0,0)`，距离平方恰好 0.25，这一密度关通过。若法线改为 `(0,0,-1)`，点积为 −1，已有根不参与这一排除。示例没有模拟后续墙约束。

## 一次请求怎样创建多条枝条

`BB59CF` 调用 `usize_less_than(3)`，再加 2，因此候选尝试数为 2、3 或 4。该辅助函数已解码：掩码后超过或等于上限则重抽，上限 0 返回 0；不是直接取模。

每次取随机值 `U∈[0,1)`，围绕当前曲线坐标 `u0` 扰动：

```text
u_candidate = u0 + (1.5U - 0.75) / L
```

`L` 来自当前曲线长度字段（`BB5505` 保存，`BB5BC2` 使用）。超出 `[0,1]` 的候选跳过，不绕回另一端；NaN 与无穷进入断言失败分支（`BB5BD1–BB5C05`）。之后还读取空间栅格墙段，构造局部旋转和范围检查；完整局部排除盒的各轴尺寸含义尚未全部恢复，不写成已确认的统一碰撞规则。

候选通过后 `BB5AF4→BF3A80` 创建 Ivy。调用指定点数限制下界 20、上界预算 `B`；创建函数取：

```text
max_points = 20 + usize_less_than(B-20)
```

常规预算 `B=70` 时为 `[20,70)` 的整数，限制是点数，不是世界长度。另有标量随机取自 `[0,1)` 或 `[0,3)`，取决于原始模式；写入 `Ivy+88`，下游按等待量消费，见 [22](22-tiny-glade-ivy-growth-and-wall-following.md)。完整时钟单位与调用频率仍未知。

## 预算不是已经生成的点数

入口先累计每条 Ivy 的 `point_count−1`，记为 `S`，要求 `S+19≤39999`。每个尝试前执行（`BB5B11–BB5B3F`）：

```text
A = 40001 - S
B = min(A,70)
S = S + B - 1
若 S >= 40001 或 A < 20：跳过这个尝试
```

这个本地预测计数在候选被后续拒绝时也已经增加，不能把它当成实际提交点数，也不能据此保证全游戏恒定不超过某个总数。

**构造演算。** 初始 `S=0`，第一次尝试预算为 70，预测 `S=69`。即使候选检查失败，第二次仍从 69 出发，得到 `S=138`。若第一次成功，随机整数抽样取 17，则该 Ivy 点数限制是 37；标量抽样 `U=0.25` 且上界 1，则标量为 0.25。尝试数、成功条数、点数限制和当前点数属于不同数量。

## 状态与身份

以下布局来自创建、追加和修剪消费者的实际读写，不是完整类型恢复。

| 对象 | 已确认字段 |
| --- | --- |
| 40 字节 `IvyPoint` | `+0` 点 ID；`+8` 三维位置；`+14` 三维法线；`+20` 初始为零的标量 |
| Ivy 点序列 | `+0/+8/+10/+18` 为环形队列容量、指针、头位置和长度 |
| Ivy 内嵌根点 | `+28` ID、`+30` 位置、`+3C` 法线、`+48` 标量；与队列元素分开保存 |
| Ivy | `+20` Ivy 身份、`+60` 关联墙身份；`+50` 点数限制；`+58` 点 ID 计数；其余状态见后续专题 |
| `IvyStorage` | `+40` 新 Ivy 的身份计数，按此键插入 map 后递增；`+30/+38` 为此处消费的随机状态 |

`BF3A80` 创建初始点 ID 0，并复制到内嵌根点。`Ivy+58` 初始设为 1；`BF3FD0` 每次追加先递增这个计数，再存入点，因此第一次追加的 ID 是 2。不要把点 ID 当作当前队列下标或假设必连续。

**身份演算。** 一个新 Ivy 的队列是 `[0]`，内嵌根 ID 也是 0，计数为 1。追加一次后为 `[0,2]`，计数为 2；再追加得到 `[0,2,3]`。修剪根端时会把新的队首复制到内嵌根点，详见 [修剪与变化](24-tiny-glade-ivy-pruning-and-updates.md)。仅删尾部不会因此重排所有点 ID。

## 已回答与缺口

已回答：局部入口门控、两类起点来源、投影与侧偏移、根点密度排除、候选数量与局部预算、创建参数、点序列及身份。
