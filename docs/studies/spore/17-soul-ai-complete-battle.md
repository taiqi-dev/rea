# 17 完整战斗算例：选目标、选手、断肢与换肉体

[目录](README.md) · [算法与结构](16-soul-ai-body-assessment.md) · [执行生命周期](11-action-plans-and-execution.md)。全部身份、数值、时间和攻击事件为**自研构造场景**，不是 Spore 实测或用户游戏现状。

## 场景与固定规则

灵魂 S 控制 B1，控制代次 7，灵魂能量 55。任务是保护同伴 A 并清除两个敌人。A 剩余 24 HP；近处守卫 G 为 60 HP，远处施法者 C 为 30 HP。

教学前提：战斗信息允许看见生命与蓄力；位置稳定、射线无遮挡、无需接近即可使用下表的合法攻击。概率是评分输入，实际事件结果另行指定，不能用“期望伤害”直接扣敌人生命。所有执行动作共享一个主动作槽，允许感知更新，期间不同时开始第二个主动作；多动作并行可随后扩展。

| B1 部件 | 能力 | 当前状态 |
| --- | --- | --- |
| RF 右前手 | 等级 3 爪击、符印施法；骨链总长 1.6 m | 空闲、健康；支点 (0,0.4) |
| LF 左前手 | 等级 2 爪击、符印施法；骨链总长 1.2 m | 持物通道占用至 t=0.8；支点 (0,-0.4) |
| LB 左后手 | 握持，不提供爪击/符印 | 不能充当攻击/施法手 |
| RB 右后手 | 握持，不提供爪击/符印 | 不能充当攻击/施法手 |
| 腿、眼 | 行走和视觉 | 正常 |

平面位置：B1 根在 (0,0)，G 的接触目标在 (1.5,0.4)，C 在 (6,0.4)。RF 到 G 为 1.5 m，距离筛选通过；LF 到 G 约 1.70 m，超过 1.2 m，且当前占用。RF 到 C 为 6 m，爪击失败，但 8 m 的法术范围通过。姿态/关节/接触可行性在此设为通过，没有把距离检查当成完整 IK。

B1 自身体力 30、HP 80。G 的既有攻击会在 t=0.4 命中 B1，造成 12 HP 伤害并切断 RF（固定事件，不按断肢概率演算）；下一次攻击最早 t=4.3。C 正在施放针对 A 的 30 伤害攻击，预定 t=1.3 生效。先前观测支持上述时序估计。

| 技能/模式 | 来源与必要部件 | 命中伤害/效果 | 成本：魂/体 | 前摇/恢复 | 效果后冷却 |
| --- | --- | --- | --- | --- | --- |

| Pulse 意识脉冲 | 灵魂；无物理手 | 8；取消当前蓄力并禁止起新招 1.2 s，范围 8 m | 10/0 | 0.2/0.2 s | 灵魂 2.0 s |
| Needle 意识针 | 灵魂；无物理手 | 24，范围 8 m | 18/0 | 0.4/0.3 s | 灵魂 1.0 s |

冷却在效果提交时开始；前摇中取消释放预约，不支付、不启动冷却。成功提交即支付，命中后的效果不可因换肉体回滚。本例意识针/脉冲为直接效果；没有未落地弹体。范围、姿态、资源在提交前仍需重查。

## t=0：为什么打远处施法者，为什么用右前手

使用 16 的公式。Firebolt 的 `pHit=.85`；其它攻击/打断 `.90`；护盾及时生效估计 `.95`。C 的 30 伤害最多会扣掉同伴现有 24 HP。

对这次已在途的 G 攻击，模型给 RF 近战暴露概率 1、施法/意识动作 .5、护盾 .25、撤退 1/6，所以各自预测自身损失 R=12/6/3/2。这是显式教学估计，不是因果保证；固定实际命中与预测不同并不矛盾。T 包括前摇与恢复。表中当前施法不需要路径。

| 候选完整方案 | D | B | R | K | T | U |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Firebolt → C / RF | 25.5 | 20.4 | 6 | 1.00 | 1.3 | **1.3550** |
| Pulse → C / 无手 | 7.2 | 21.6 | 6 | .50 | .4 | .9750 |
| Ward → A / 无手 | 0 | 19 | 3 | .75 | .6 | .6325 |
| Firebolt → G / RF | 25.5 | 0 | 6 | 1.00 | 1.3 | .3350 |
| Needle → C / 无手 | 21.6 | 0 | 6 | .90 | .7 | .2600 |
| Claw → G / RF | 21.6 | 0 | 12 | .60 | .8 | .1300 |
| Retreat / 腿 | 0 | 0 | 2 | 0 | 1.0 | -.1167 |

计算例：Firebolt 对 C 若命中将击杀，t=1.0 早于 1.3，因此 `D=.85×30=25.5`，`B=.85×24=20.4`，`K=20/20=1`；`U=.85+1.02-.20-.25-.065=1.355`。Needle 单次只有 24，不能杀 30 HP 的 C，故保护收益 B=0。Pulse 可以取消当前威胁，但不能永久阻止 C 的续招。

拒绝的候选也要保存：Firebolt/LF 当前通道占用；Firebolt/LB、RB 缺符印；Claw/RF→C 当前不可达。允许生成等待/接近方案时，需要带等待或路径重新评分；本轮检查即时方案，预算与范围明确，未宣称全局最优。

**选择远处 C 是因为它正在威胁同伴，而不是因为距离最近。选择 RF 是因为它能执行该模式且空闲，而不是“取第一个手部索引”。** 只有 RF 播放符印动作，其他手按自己的持物/姿态规则工作；不能四手同时放出四份伤害。

动作 X 固定 S/B1/代次7、目标 C、RF 的稳定身份与附着代次。预约 20 灵魂能量后：存量仍 55，已预约 20，可用 35，进入前摇。

## t=0.4：断掉施法手，不继承旧动作

G 的固定攻击生效，B1 HP 80→68；RF 断裂，身体图版本 1→2。X 的精确依赖失效，取消并释放原预约令牌。灵魂能量回到存量55/预约0；C 仍30 HP，Firebolt 没有扣费、没有冷却。

新能力快照中 RF 的爪击/符印提供者消失；LF 的等级2能力仍在，但到 t=.8 前占用。LB/RB 不能被临时当作符印手。手断掉不能让 X 自动改名 LF 然后在原 t=1.0 出招。

重新评分时 G 已出招，这个决策时段没有新的自身攻击，R=0。C 原定 t=1.3 的威胁仍在。

| 当前可行候选 | D | B | K | T | U |
| --- | ---: | ---: | ---: | ---: | ---: |
| Pulse → C / 无手 | 7.2 | 21.6 | .50 | .4 | **1.1750** |
| Ward → A / 无手 | 0 | 19 | .75 | .6 | .7325 |
| Needle → C / 无手 | 21.6 | 0 | .90 | .7 | .4600 |

选择 Pulse。t=.6 效果窗口再次确认控制权与目标，消耗10，灵魂55→45；本例固定命中，C 30→22，原定 t=1.3 的攻击取消，不能起新招至 t=1.8。Pulse 冷却至 t=2.6，恢复到 t=.8。

打断是取消攻击事件，不能仅在表现层让敌人抖一下而保留原定伤害。后来 C 在 t=1.8 恢复，以观测到的1.4秒蓄力规则重新攻击，预计 t=3.2 生效；它成为新威胁，不是复活已经取消的原事件。

## t=0.8：进入另一副肉体，灵魂不重置

外部合法换体事件把 S 转到已登记、可控制、位于同一位置的备用 B2。**换体在本例由外部事件触发，不拿它冒充本轮 AI 自主搜尸/换体算法**。B2 有视觉、腿、嘴和角，没有手；HP120、体力80。控制代次7→8。

| 保留/重建 | 状态 |
| --- | --- |
| S 能量 | 仍45，不重置55 |
| S 技能与 Pulse 冷却 | 仍记得所有灵魂技能；Pulse仍冷却至2.6 |
| B1伤口、体力 | HP68、RF断裂、体力30，仍属于B1 |
| B2肉体技能 | 新增角击和咬击；不存在符印手 |
| 实时感知 | 从B2眼睛重新观测G/C/A；旧观测归带时间的记忆 |
| 老动作/回调 | X已取消；B1/代次7不能再驱动B2/代次8 |

B2 的 Horn 角击为32伤害，体力10，前摇.8/恢复.3，效果后冷却1秒；Bite 咬击为28伤害，体力8，前摇.5/恢复.4，效果后冷却1秒。角与嘴的锚点/接触范围能触及G，不能近战触及C；无需走位。本例命中估计均.9。

现在 C 剩22 HP，意识针24伤害已足以击杀；预计新威胁 t=3.2，针在1.2生效。模型保守地根据 C 的已知恢复/蓄力能力预告此威胁，不是假设看见其隐藏决策。对这段动作 R=0。

| 新肉体的完整方案 | D | B | K | T | U |
| --- | ---: | ---: | ---: | ---: | ---: |
| Needle → C / 无手 | 19.8 | 21.6 | .90 | .7 | **1.4800** |
| Ward → A / 无手 | 0 | 19 | .75 | .6 | .7325 |
| Horn → G / 角 | 28.8 | 0 | 1.00 | 1.1 | .6550 |
| Bite → G / 嘴 | 25.2 | 0 | .80 | .9 | .5950 |
| Needle → G / 无手 | 21.6 | 0 | .90 | .7 | .4600 |

Firebolt 知识仍在，但全部手势方案因 B2 无提供者被拒绝；Pulse 因灵魂冷却被拒绝，换肉体没有绕过它。选择 Needle→C；预约18后45存量/18预约/27可用。t=1.2固定命中，支付18，灵魂45→27，C22→0；多出的2伤害不重复获得有效伤害收益。冷却至2.2，恢复至1.5。

t=1.0 若旧 X 的动画效果事件到来，先因Cancelled拒绝；控制代次也已不匹配。它不能额外扣20，也不能从B2角的位置放火球。取消不是把未发生的火球记成“命中失败”，它应记为执行被断肢中断。

## t=1.5–3.1：重新选肉体技能，完成战斗

t=1.5，C已死，同伴威胁B=0，G60HP且下一次出招最早4.3。针仍冷却，角击U=.655高于咬击.595。选择 Horn→G，由**角**执行，腿提供支撑/姿态；不是把整个身体每个部件各算一次攻击。

t=2.3 固定命中，G60→28，B2体力80→70。角击冷却至3.3，恢复至2.6。提交完成后即使角后来断裂，也不回滚32点伤害。

t=2.6 再评价：

| 候选 | 关键变化 | U |
| --- | --- | ---: |
| Bite→G/嘴 | 28伤害，期望有效25.2；T=.9、K=.8 | **.5950** |
| 等待角冷却再Horn→G | 等.7+动作1.1=T1.8；伤害收益按剩28HP截断，K=1 | .5000 |
| Needle→G/无手 | 可用但花18灵魂能量；期望21.6、T=.7、K=.9 | .4600 |
| Pulse→G/无手 | 期望7.2，无同伴威胁可取消，T=.4、K=.5 | .0950 |

选择 Bite，t=3.1 固定命中，G28→0，B2体力70→62，战斗结束；恢复到3.5不再产生攻击。A仍24HP，S能量27，B1仍保留HP68与断手，B2HP120。两敌已死，其未提交的未来攻击被取消。

如果固定结果改为针未命中，则C仍22、灵魂成本仍支付；不能沿用“C已死”的续篇。应按新观测更新目标生命与威胁、尊重针冷却后重新评分。本轮只演算这条明确分支，没有把一条成功轨迹当作所有随机结果。

## 可复现的执行伪代码

```text
TryStart(plan):
    in authoritative simulation transaction:
        CheckControlLease(plan)
        CheckTargetIdentityAndCurrentConfirmation(plan)
        CheckExactProvidersChannelsPoseAndCooldowns(plan)
        CheckCostsMinusExistingReservations(plan)
        action = NewAction(plan, exactProviderGenerations, costOwnerKeys)
        ReserveAllCostsAndChannelsOrNone(action)
        action.phase = Windup
    return Started(action.id)

CommitEffect(actionId, ordinal):
    action = LookupAction(actionId)
    if absent: return Rejected(UnknownAction)
    if action.phase != permitted: return Rejected(ActionNotActive)
    if ordinal in action.committedOrdinals: return DuplicateIgnored
    in authoritative simulation transaction:
        RevalidateControlDependenciesTargetAndEffectGeometry(action)
        if invalid: return CancelAndRelease(action, detailedReason)
        ConsumeOriginalReservationTokens(action)
        result = ResolveHitAndApplyActualEffects(action)  # 不扣期望伤害。
        StartCooldownOnItsDeclaredOwner(action)
        MarkOrdinalCommitted(action, ordinal)
        action.phase = Recovery
    return result

CancelAndRelease(action, reason):
    if already terminal: return AlreadyTerminated
    StopOnlyAnimationsAndChannelsOwnedBy(action.tokens)
    ReleaseOnlyUnconsumedOriginalReservationTokens(action)
    PreserveCommittedEffectsAndPaidCosts(action)
    MarkCancelledWithCleanupStatus(action, reason)
    ScheduleFreshDecision()
```

取消与提交同一模拟时点时使用明确事件排序与原子判定。本例定义功能失效事件先于尚未提交的攻击窗口；若效果已经先提交则不回滚。不要依赖动画线程回调先后决定伤害。多段、持续、群攻技能还需自己的ordinal/目标去重与分段成本规则，见11。
