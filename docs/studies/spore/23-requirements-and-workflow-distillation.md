## 需求归纳与适用范围

| 需求 | 当前理解 | 去向 |
| --- | --- | --- |
| 明确选择产品阶段/子系统 | 本次仅登陆后的陆地生物阶段及编辑器，排除水中、部落、文明等玩法 | 本研究；通用技能保留“沿用范围”规则，不固定Spore阶段 |
| 服务于自己的产品开发 | 参考拼装、任意肢体动作、技能执行和群体行为；交付可独立实现的规格 | 通用技能区分原作问题与自研问题 |
| 深入结构和算法 | 解释输入、状态、核心表示、选择分支、具体执行对象、更新与失败，而非功能名称列表 | 机制研究参考文档 |
| 完整具体算例 | 沿用一组状态和对象说明决策、执行、变化及结果；涉及评分时核对算术 | 机制研究参考文档 |
| 目录化长期文档 | 按模块分文档，保留索引、阅读路线、证据和未知，续查沿用已有路径 | 交付参考文档 |
| 灵魂与肉体 | 灵魂既影响策略也有自身技能；断肢/换体重新评估能力、目标与执行部件 | 用户游戏专属需求，保留13–17，不强制其他产品采用 |
| 更广泛但有边界的参考 | 身体材质、花纹、巨型实例、敌人来源、族群、配合与社交 | 已有18–22；不能推广成每次研究都查整款游戏 |
| 不要求一直运行目标 | 静态研究可以关闭游戏；真正需要运行证据时说明具体场景 | 静态fallback规则 |

这些是同一会话的明确需求与当前归纳。没有跨日期的独立证据支持将其全部提升为全局个人原则；本次授权更新的是REA项目通用调查技能。未改全局AGENTS、personal技能或个人决策账本。

## 助手踩坑与修正

| 观察/问题 | 本轮证据 | 修正与可复用规则 |
| --- | --- | --- |
| 原生分析入口不可用 | 00与历史记录保留：没有REA MCP，公共启动器缺少编译产物，有界检查未找到可用provider | 保留阻塞类别，继续有证据支持的部分；状态不变时不反复诊断，不以研究任务默认安装工具 |
| PE节坐标曾写错0x200 | [历史报告](notes/initial-multi-leg-study.md)明确更正raw/RVA起点；换算差值未变 | 从实际节表计算；区分文件偏移、RVA、首选VA、运行地址和社区对象字段偏移 |
| 广泛关键词产生假相关 | 族群扫描包含Packet、其他阶段与库词汇 | 有界候选清单再筛选，完整字面量与包含关系分开，命中数不作结论数量 |
| 名称和声明被误读的风险 | `mHuntingStyle`注释未初始化，decider有回调但未恢复函数体；自研灵魂机制原作未证实 | 直接来源、版本和实际使用者分别核对；不把自研评分/灵魂系统写成原作实现 |
| 合并读取输出过大 | 工具报告预览截断；本轮整理技能时过宽搜索也再次触发 | 先限制路径和主题，每项返回保持可审阅；保留结果后选段读取，不能把截断输出视作完整记录 |
| 公开PDF超读取限额 | 官方手册约13MB，网页读取失败；镜像同样未解决 | 使用现有PDF解析器直接读相关完整页面，保存摘要、页码和文件身份；不反复换镜像或保留不必要的全文 |
| 沙箱网络读取失败 | 公共GitHub请求返回DNS解析失败，正式升级权限后读取成功 | 只能确定普通调用失败而升级调用成功；不据此断言外站故障或具体DNS根因，也不改全局网络/客户端配置 |
| 手写续篇路径错误 | 尝试读取19的错误文件名，实际目录索引给出正确路径 | 优先读取现有索引或文件清单，不凭记忆拼模块名称；不存在的文件不能冒作已读 |
| 检查范围与统计易漂移 | 新增目录链接后相对链接从101变为103，并已同步当轮记录 | 当前修改后核对当前记录；历史验证数量只代表当时范围，不反复跑无关构建 |

这里只记录可观察的操作问题和证据，不将助手失误蒸馏成用户人格或偏好。目标事实和工作流事实也分开：PDF读取成功证明相关页面已读，不证明游戏运行；独立算例通过只验证构造规格。
